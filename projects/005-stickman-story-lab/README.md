# 005 · 角色与故事工坊

原创短片《第二副餐具》已完成：30秒、1080p、六个真实图生视频镜头、双人中文配音、环境声与中文字幕。先看成片，再查看角色、故事、分镜和制作资料。

**能力：**以定制角色配合故事，通过分镜、场景视觉、图生视频和配音剪辑形成短片。阿灯是我们实际走完这条路线的样例；原帖底层模型与实现方式仍未确认。

**本质：**定制角色＋故事。角色的身份、渴望与弱点决定它如何行动，故事通过选择与变化赋予它独特性；人把握情绪与取舍，模型协助展开故事和实现表达。

**价值：**把情绪转成可观看的表达，并积累可延续的角色、经历和素材，为下一部故事提供基础。是否产生共鸣仍需观看反馈，跨故事延续是后续创作方向。

## 已完成的原创样例

阿灯习惯为别人留一个空位，却害怕开口邀请。一个前来问路的旅者，让它第一次试着问：“你……吃饭了吗？”故事从独坐走向同桌，用停顿、视线和小动作表达期待。

- 完整成片：`web/sample/second-place-30s-v1.mp4`。30.000秒、1920×1080、24fps、720帧，H.264视频与48kHz AAC音轨。
- 视觉素材：1张角色设定图、6张场景首帧；使用内置ImageGen，具体底层模型版本和种子未知。
- 动态镜头：6条Kling V3实际图生视频，剪为每镜5秒。S04复用最初测试，另外生成S01、S02、S03、S05、S06。
- 声音：阿灯与旅者的四句普通话合成对白，加上程序合成的室内底噪、脚步、纸张、布料与餐具声。原生成音轨已替换，未使用音乐。
- 字幕：中文对白字幕已烧录，另提供 `web/sample/second-place-30s-zh.vtt`。
- 完整方案：`web/sample/plan.json`；剪辑清单：`web/sample/film-manifest.json`；实际生成提示词：`web/downloads/generation-prompts.json`；剪辑、声音、费用及限制：`web/downloads/production-record.json`。

成片与创作拆解页支持按镜头跳转、暂停和下载；角色身份、故事意图、首帧与实际输出均有记录。

## 创作主线

角色定制身份，故事赋予灵魂，人把握情绪，模型辅助故事和分镜，图生视频实现动态表达。

人提供创作意图、真实细节并判断表达是否真诚，模型协助发展情境、冲突、选择与分镜。本项目已实际完成这条图生视频制作路线；情绪是否成立、人物是否可信，仍需观众反馈。角色带着过去的经历进入后续故事，是继续创作的方向。

## 制作记录与限制

- 视频费用累计528积分：S04实际扣88积分，新增五镜共440积分。
- 最初S04测试为 `web/sample/s04-invitation-v2.mp4`，1920×1080、24fps、5.04秒、含原生成AAC音轨，任务1036213。精简动作描述后成功；此前四次提交10061的确切根因仍未确认。工具当时估价60积分，实际扣88。
- S02重新构图以排除原生成画面边缘的多余路人。杯子花纹、围巾细节与手部形态仍有轻微跨镜变化，保留为首版样例。
- 中文混音和最终MP4均经过独立自动转写核对，四句台词一致；自动核对不等同主观听审。已检查实际字幕画面，无缺字方框。
- 成片曾在浏览器从0秒播放至30秒，媒体无错误，镜头跳转可用。公开发布验证见 `notes/release.md`。
- 网页展示制作成果与过程，未提供在线生成服务。跨故事角色记忆、多语言成片和批量生成仍为扩展方向。
