## 发布与自动检查

`build-research-content.mjs`从两个明确的整理JSON生成content.json；`build-research-library.mjs`从三项目白名单生成资料、媒体与原始结果索引。图片内容哈希命名，保留origin，重复源图去重；不删除原文件或扫描项目外数据。研究JSON只在档案页面加载，主场景运行依赖中没有研究页代码或资料请求。

```powershell
node projects/017-abyss-expedition/src/build-research-content.mjs
node projects/017-abyss-expedition/src/build-research-library.mjs
node projects/017-abyss-expedition/src/check-research-library.mjs
node projects/017-abyss-expedition/src/check-research-site.mjs --base-url=http://127.0.0.1:8017/
node projects/017-abyss-expedition/src/check-delivery.mjs
```

集成检查验证9个模块HTTP内容与文件一致、图片映射存在、22章证据对应、报告阅读链接与跨项目网页参数保留，并递归检查43个场景运行模块不依赖档案运行时。静态检查的browserUXVerified=false有意保留，实际UI覆盖由上表单独记录。

015页脚、016玩法说明、017作品与原技术页都已添加研究档案入口。旧作品服务仍各自使用8015／8016；全部归档图文仅需8017。
