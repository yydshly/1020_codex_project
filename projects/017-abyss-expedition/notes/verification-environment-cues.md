# 环境语音与三维画面联动验收

日期：2026-10-25。服务：`http://127.0.0.1:8017/`。本轮不修改既有12条环境音轨或22条导演音轨。

## 交付行为

12段环境讲解拆成55个按语句顺序排列的提示。实际音轨进度驱动当前提示、三维高亮与教学动画；切章、拖动、提示定位或暂停都使用同一秒数回算。新增层不选择航次事件、不操纵相机、不写个人报告。

- **岩壁与海床**：在原网格高度上作透明面选、层线和轮廓。远处固定观察站保留真实位置；驾驶点附近另寻找实际可见的陡壁或海床作为近处观察例子，周围没有陡坡就不造墙。
- **水流**：在近处水体显示三维流线和移动箭头，标为教学示意；不把方向、速度或输送量当作实测。
- **海洋雪**：在镜头能看到的真实水体中显示缓慢沿世界Y轴下沉的颗粒和辅助下箭头；不会放到岩体内部，也不是上升气泡。
- **生物与装置**：原位光环、指示杆和目标标签；珊瑚、海绵、管虫、烟囱和采水架不因讲解而移动。远处、身后、画外或被岩壁挡住的对象有明确位置提示。
- **自由控制**：提示层没有相机或驾驶控制权。可继续前后、升降与转镜头；“画面提示”可独立关闭而不停止语音。展开后的提示按钮只暂停并定位当前音轨，继续播放后恢复按语句推进。

基础海水、车辆和原有生态视觉继续运行；暂停冻结的是本轮讲解提示动画的时间相位，不是把整个自由驾驶世界暂停。

## 时间依据与精度

`narration-cues.mjs`是新增第九个跨主题纯核心。数据中的quote为原旁白精确连续文本；本地ffmpeg从12个MP3提取122处停顿锚点，再以标点匹配和段内文字权重插值估计提示时刻。它没有自己的时钟，不依赖DOM或Three.js，反向seek直接按秒数重算。

这是**停顿辅助的短语估时**，不是逐词强制对齐。最长未锚定跨度约7.664秒；与纯文字预测的校正量也不能当作实际逐词误差。相关方法、音轨SHA和质量元数据保留在 `environment-cue-timing.mjs`。生成时间表全程本地、零网络，原音频字节未改。

## 实际浏览器覆盖

| 验证 | 观察 |
| --- | --- |
| 用户原机位的岩壁 | 原先暗且易选背面的框选改为相机可见的真实陡面；近处壁面、金色层线与标签可见。远西壁仍按真实位置标记 |
| 水流→海洋雪自动切换 | 从8.8秒的水流提示继续播放，9.895秒仍为水流，11.345秒自动成为海洋雪；没有点击雪提示来触发这次切换 |
| 讲解中继续驾驶 | 上述跨句播放同时按R升高，Y由约-205.3经-171.2到-142.8；语音仍playing，航次仍第90分钟、报告仍0条 |
| 手动定位与镜头 | 在原机位从雪定位到珊瑚/海绵提示，前后URL中的cam完全相同；只改变音频秒数与提示 |
| 暂停与反向定位 | 暂停后提示秒数保持；可从后面的生物提示跳回海洋雪或水流，当前类型、动画相位和音频位置随之恢复 |
| 画面提示开关 | 关闭后overlay隐藏、标签0个、chips无选中，语音仍播放；重新开启立即显示当前提示，不重播音轨 |
| 生物原位与画外 | 原谷道位置提示珊瑚在画外、海绵在身后；到真实珊瑚台航次位置后，珊瑚与原位光环可见，海绵仍在原处且显示方向 |
| 独立镜头 | 切3并拖动镜头，提示保持同cue、暂停秒数0.00，潜器位置不变，目标标记按新视角重投影 |
| 手机布局 | 390×844 CSS视口，无页面水平溢出；收起提示约137像素高，下缘约307，驾驶台上缘约489，有独立观察空间；不是实物手机测试 |
| 跨航次与重复目标 | 驾驶中切到热液后保持手动模式，旧峡谷提示清理；含overview/vent/biology副类的照片提示仅保留chimney、plume、garden三个唯一标签 |
| 退出清理 | 结束驾驶后环境面板和提示overlay均隐藏、标签数0，环境音轨暂停 |

提示标签去重，避免同一实体由overview和副类型同时出现时留下重复指线。画内但被岩壁遮挡的对象显示“前方岩壁遮挡”，不会被误指成右侧画外目标。标签层位于场景暗角之上，并避开导览与驾驶控件；可见对象有引线，画外对象按箭头方向寻找。

检查时应用控制台无新增warn/error。部分冷启动或快速连续操作曾超过浏览器控制工具的等待期限，下一次状态读取正常；本轮不宣称帧率、所有硬件或长期运行性能已经达标。
