# 场景补全与导演模式：实际验收

2026-10-24，本地入口 <http://127.0.0.1:8017/>。导演入口：<http://127.0.0.1:8017/?dataset=vents&film=vents-establish>。

## 目标与实现

把散落的模型组织成一次能看懂的科考：水面母船通过脐带连接 ROV，潜器从平台沿岩脊寻找喷口，再观察群落、取背景对照，最后沿信标返航。水柱采用压缩纵向尺度的教学示意；地形、航次和读数不代表真实海域。

新增母船、水柱、脐带连接、低矮岩屑、近底漂移、水体瓶架、沉积取样器和回收信标；语义标签说明物体身份。不同采样设备由 appearance 字段选择，管虫/珊瑚/海绵的区别保留。

导演时钟独立于航次时钟。热液脚本 127 秒、峡谷脚本 126 秒，各七镜头；每镜引用既有事件 ID，选择对应航次分钟，再让机位规划器执行。导演不自动创建或清空个人记录，只有用户点击采样才会写入记录。

## 浏览器与交互证据

使用 Codex 内嵌浏览器，桌面 1280×720 与用户正常窗口 970×871，窄屏 390×844 CSS 视口。没有宣称实体手机或所有显卡兼容。

| 流程 | 实际操作与结果 |
| --- | --- |
| 看懂现场 | 普通视图新增地点、角色与任务说明；导演开场能看到母船、吊架、海面和向下的脐带，随后进入海床调查。 |
| 进入导演 | 点击导演入口后收起普通探索面板和航次时间轴，出现独立影片时间线、章节、字幕、镜头方式和速度控制。 |
| 暂停锁定 | 在喷口镜头暂停于影片 34 秒。间隔后影片时间、语义标签投影坐标均一致，截图 JPEG 字节完全一致；保留 pause-a.jpg 与 pause-b.jpg 供校验。 |
| 跳章与拖动 | 暂停时选择第 3 镜立即显示喷口环绕，影片 34 秒对应航次 38 分钟；拖动进度可切到采样和返航。显式跳转直接落到规划机位，自动换章保留缓入。 |
| 手动导演 | 切换“局部特写”会暂停放映并切换景别；可恢复“按分镜脚本”。字幕可收起和显示，控件持续可用。手动景别只在当前会话保存。 |
| 全片自动播放 | 热液片从 0 秒开始以 2× 连续放映，墙钟 69 秒时检查已到 127 秒、第 7/7 镜，显示完成提示和重播按钮，没有自动循环。镜头/控制器未因绘图而停止。 |
| 结束与重播 | 点击重播后回到第 1 镜、影片 0 秒，完成提示消失。 |
| 场景细节 | 实际检查喷口环绕、管虫特写、瓶架和背景站。发现瓶架被前景挡住后修正采样专用构图；影片 88 秒的瓶架已完整可见。 |
| 退出自由探索 | 从返航镜头退出后停在回收信标，普通相机按钮恢复，film 参数移除；手机端退出后也可继续当前站点。 |
| 章节分享 | 分享第 3 镜后 URL 含 film=vents-discover，不含自由 cam；刷新后暂停在该镜头起点 34 秒，字幕与模型一致。 |
| 键盘与焦点 | 进入导演后焦点落在播放按钮，空格可暂停；退出后焦点回到三维画布，避免停留在已隐藏的导演按钮上。 |
| 图层隔离 | 自由模式关闭地形、航迹、喷流与物体标注，再进入导演，电影仍显示完整场景；退出后勾选保持关闭。测试结束恢复原测试设置。 |
| 切换航次 | 播放中切到峡谷，旧放映立即结束，普通视图与新航次内容恢复。峡谷另检查了开场自动推进到岩壁、珊瑚/海绵章节的手动跳转、126 秒片长；没有把热液全片测试冒充峡谷整片测试。 |
| 手机 | 390×844 下导演画面与控制台可见，章节、播放/暂停、字幕、退出均可操作；导演 clientWidth/scrollWidth 均 390px，退出普通视图后均 375px（滚动条占宽），没有页面水平溢出。 |

最终加载时段浏览器控制台无 warn/error。首次加载需要编译 WebGL 材质；一次等待工具在加载已隐藏后超时，随后读取 DOM 与截图确认页面已就绪，没有把工具等待结果当作应用通过或失败。

本轮修复的中间问题：暂停跳转到 0 秒仍留在旧镜头；岩屑材质与实例颜色双重相乘导致纯黑点；水体采样器被山脊遮挡；回收信标语义标签误称平台。这些都经过修正和后续实际画面检查。

## 自动检查与复用边界

- check-core.mjs、check-camera-state.mjs、check-director.mjs、check-delivery.mjs 通过。交付检查覆盖 32 个本地链接、14 个镜头与既有事件/实体引用、第三方及材质哈希。
- 新旧 9 个主要 JS/ES 模块语法检查通过；导演核心另用仓库巡检影片夹具验证领域独立性。
- git diff --check 与最终全仓库目录检查通过（17 个项目）。检查期间另一个项目的元数据曾在更新，最终目录已同步；没有修改该无关项目或覆盖它的工作。
- 通用核心由五个增至六个，新增 director-core.mjs。director-ui.js 是浏览器适配，shot-camera.mjs 仍使用本场景单位与构图约定，expedition-context.mjs 是 Three.js 主题几何组件。
- 当前只有字幕解说，没有解说音轨、视频导出、真实流体或设备控制。不是对真实科考操作规程、物种或测深数据的复原。
