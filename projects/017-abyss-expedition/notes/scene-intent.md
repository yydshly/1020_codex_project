# 深海场景的选题与导演叙事

选深海科考，是为了把源库的时间推进、地点选择、路线与事件联动迁移到另一类主题。历史地图和深海航次都能由稳定实体、按序事件和空间路线组织内容；深海还能检验三维尺度、遮挡、机位和真实几何的配合。

此前首先证明了核心模块可迁移，却没有完整交代“身在何处、谁在观察、正在做什么、为什么要去下一站”。本轮把这些问题写进场景说明和镜头顺序：水面观察组通过脐带连接 ROV，潜器沿海床建立观察与对照，最后沿信标返航。

## 两条短片的调查逻辑

热液航次：建立母船—潜器—海床的关系，先读岩脊，再发现矿物烟囱与羽流，观察附近管状群落，移到外缘和背景站，最后回望整条调查路线。黑羽流解释为悬浮矿物颗粒的视觉表达，避免被误读为火焰或燃烧。

峡谷航次：先建立入口与深槽的方向，沿壁辨认尺度，在珊瑚台看枝状形态，比较沉积海床，再深入通道、观察管杯状海绵，沿标记返航。重点是把群落外形和它所在的地貌一起比较。

两条短片各七镜头，初始镜头表为热液 127 秒、峡谷 126 秒；配音接入后由实际音轨时长更新，最终片长以生成的音频清单为准。影片秒数与航次分钟是两条独立时间尺度；导演播放通过事件 ID 选取教学航次的相应观察时刻，不把短片时长解释为真实潜航耗时。

## 通俗旁白修订

用户反馈看不懂原解说后，十四章改为直接讲眼前的对象、要做的动作和要回答的问题。热液片的主线为：水面科考船放出黄色无人潜器，潜器进入没有阳光的深海，找到流出热水与矿物的黑烟囱，看清管虫与食物来源，再去采水、取泥作背景对照，最后沿信标返航。峡谷片依次讲岩壁、珊瑚、泥沙取样、深谷采水和海绵，结束时把照片、样本与位置带回母船。

本次每章旁白为 69–79 个汉字，标题和最多两条提示也使用“采水瓶、取泥管、岩石台面”等具体称呼。教学水深、设计数据与纵向压缩说明集中放在航次 notice，不打断旁白主线。稳定的镜头 ID、实体 ID、事件 ID 和 framing 保留，以便生成音频和相机编排共用同一份文本；配音生成开始后冻结旁白，避免清单与字幕失配。

## 镜头数据与接口

数据位于 `web/data/director-shots.mjs`。`getDirectorShots(missionId)` 返回深冻结数组，未知航次显式抛 `RangeError`；`directorMissionBriefs` 提供标题、地点、观察角色、任务与教学边界。

每个镜头都引用现有 `entityId` 和 `eventId`，用 `duration` 指定影片秒数，`title/narration/objective` 说明看什么和为什么看。`callouts` 最多三项，适合配合场景语义标签或讲解卡，不能据此声称画面里有实际不存在的设备。

| framing | 叙事职责 |
| --- | --- |
| establishing | 建立整体现场、上下关系和航次方向 |
| approach | 从已知参照靠近下一处观察目标 |
| orbit | 围绕主体辨认轮廓与相对位置 |
| detail | 暂时减少背景，观察具体结构或形态 |
| compare | 把当前位置放回前后观察线索中思考 |
| departure | 拉回路线与整体现场，结束调查并交还控制权 |

导演核心负责播放、暂停、跳章与进度；镜头适配器负责将 framing 和进度转换为相机位姿，教学文案负责角色与调查逻辑。三者分开后，其他主题可复用控制器和镜头契约，再替换角色、事件、视觉对象与叙事内容。

这些镜头是编写的教学脚本，不模拟流体或真实设备控制。MiniMax 配音由独立生成器产出，实际音轨与时长以音频清单为准；本文件不调用语音接口。地形、海域、航次与读数均为设计数据；管虫、珊瑚和海绵为形态示意，不用于物种鉴定。影片播放不自动生成个人采样记录。
