# 继续完善：画面与交互验收

本轮改善冷灰岩面、水体层次、潜器框架与灯光、珊瑚枝体和近景航迹呈现；保留独立 Three.js 场景与程序化地形。视觉证据用于展示实际结果，不宣称已达到参考库的内容深度或完成度。

## 浏览器实测

Codex 内嵌浏览器；1280×800 桌面、正常窗口 970×871、390×844 CSS 窄屏。窄屏可用宽度因滚动条为 375 px，并非实体手机兼容性测试。

| 操作 | 实际结果 |
| --- | --- |
| 站点选择 | 黑烟囱群、热液生命花园与冷水珊瑚台自动切换到目标近景；观察对象、记录方式、对比线索随实体更新。 |
| 完整导览 | 逐次经过热液航次 8 站，最后打开航次报告；手动换站退出导览。导览中打开、关闭报告后仍保留原进度。 |
| 相机链接 | 真实拖动改变镜头，分享后刷新，URL 中 cam 保持一致；跟随模式同样验证。位置与目标按 0.1 量化。 |
| 图层链接 | 关闭海底细节与粒子，fx 为空；刷新后两个开关仍关闭；恢复开关后重新显示。路线与标签仍由时序核心编码。 |
| 途中状态 | 45 分钟显示“途中模拟读数 · 前往热液生命花园”；观察卡仍明确标出上一个站点事件为 38 分钟。 |
| 回放 | 开始、暂停按钮状态正常，时间轴能继续推进；切换航次后读取第二套站点与事件。 |
| 记录与比较 | 记录玄武岩、羽流、群落三项，进度 3/3；已记录按钮禁用；比较显示两站位置、时刻、水深和观察线索，选相同站点时要求重新选择。 |
| 真实导出 | 浏览器下载 JSON，核对格式 v1、goal.complete=true、3 条样本；每条包含事件、观察说明、missionTime、来源与记录时间。存档见 example-polish-report.json。 |
| 窄屏 | 场景、观察卡和报告比较均可操作；页面 scrollWidth 与 clientWidth 相同，报告表格宽度小于对话框，无水平溢出。 |

测试前热液记录数为 0；本轮创建的三条测试记录已通过页面按钮清空。其他航次未写入测试记录。最终页面保持实际作品，可自行开始记录。

- check-core.mjs：两条航次与非海洋夹具、时序、查询、插值、异步保护、原模块字节一致性通过。
