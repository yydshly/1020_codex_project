## 发现与修改

| 旧版可见问题 | 本轮处理与检查 |
| --- | --- |
| 光滑丘陵、规则低面石块，像几何沙盘 | 新增terrain.js：320×320网格、分尺度山脊/峡谷、侵蚀细节与等深线；移除棋盘和矩形台座，底床延伸到水体雾中 |
| 单一漫反射，缺岩面细节 | 接入Poly Haven CC0岩面diffuse/normal/roughness，坡度与沉积区着色、凹陷阴影；保留原始3文件哈希 |
| 重复大型物体、等径烟囱和放大潜器 | 调整比例，烟囱加入不规则矿物外壳与结壳；近景可辨底座、羽流和潜器主体 |
| 浮卡盖住场景，文字偏小 | 200px导航、场景、286px独立详情；头部60px、时间轴88px；正文13–14px、主要控件12px以上；1280×720时场景794×572，与详情不相交 |
| 标注同权重，路线弱 | 按距离和站型取舍标注，选中浅色标注、独立ROV标记、已访/未访路线；清除选中标签重文字阴影 |
| 近景前景挡住目标，ROV与烟囱重叠 | 站点邻域连续缓坡；潜器偏移且按自身落点抬升；近景/跟随视线采样避障；相机方位与ROV偏移方向错开。09截图中烟囱在左、ROV在右，主体与底座可见 |
| 采样入口不易发现 | 靠近/采样按钮移到站名和深度之后，两列38px高，初始详情即可操作 |

新增水深剖面使用已有关键帧和事件。实际选择62分钟可同步到生命花园，位置指示更新，并可继续采样；不改变地形为教学模拟的事实。

## 回归范围

本轮实际检查两航次切换、黑烟囱与珊瑚近景、剖面事件、采样与报告、图层开关、俯视、跟随回放、970宽度布局、390×844 CSS窄屏布局。970×871时场景540×723、详情250px，页面无横向溢出。窄屏不是物理手机测试。控制台检查无error/warn。

核心行为检查、交付文件校验、场景模块语法检查通过。静态检查包含4个三维库原始文件及3个CC0材质文件哈希。

## 范围边界

本轮改善地形材质、站点可见性和信息布局。作品仍使用两条虚构航次、程序地形和设计的遥测数据，没有复现源库的历史数据规模、逐城知识深度或真实海床测绘。视觉判断以当前画面为依据，不以模块或测试数量代替。
