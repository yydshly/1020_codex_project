# 东坡南行首版验收记录

日期：2026-10-24。范围：016 独立静态作品；015 原作能力展示与手册保留。运行入口为 http://127.0.0.1:8016/ 。

## 用户主线

打开作品 → 从地图或站点选择黄州 → 浏览惠州 → 到达儋州 → 回到路线总览。选择时，地图位置、年份、人物经历与诗文同步，资料可继续展开。

| 边界 | 结果 | 证据 |
| --- | --- | --- |

- 下一站：惠州 / 1094 / 惠州地图标记一致。

- 点地图惠州标记：返回惠州，年份与 URL 同步。
- 放大、全线视图、复位：SVG viewBox 随操作改变；全线视图保留当前叙事。
- 鼠标平移：拖动前后 viewBox 不同，再复位成功。
- 地图全屏：进入与退出按钮状态正常。
- 来源：关于这条路、逐站资料入口可展开，来源链接带安全的新窗口属性。

## 实测产生的修正与边界

1. 上游儋州行迹点位接近今城。本项目参考昌化军古治所资料，改用中和附近 [109.35, 19.74]；不是故居测绘坐标。
2. 不把 1080 抵达黄州与 1082《定风波》合并，也不把 1100 渡海诗标为 1097 年作品。惠州诗作按居惠时期呈现并提示异文。
3. 手机三站从横滑改为常显，提高正文可读性，选站后滚到对应正文。
4. 引导图首轮内嵌截图的格式与扩展名不一致，实屏查看发现空白；将浏览器实际 JPEG 字节规范保存为 PNG，并加入格式断言，重新生成后整图检查正常。
5. 本地服务器在会话恢复时已停止，已重新启动 8016，并恢复 8015 原展示。网页运行不需两者互相访问。

范围：三站专题，不是完整年谱；连线省略任职与途经地点；水系和地形用于参照，不复原古河道。部分外部学术来源正文访问可能受限制。新增代码与地图素材的条款分开记录在 NOTICE.md。
