016 / 历史时空地图

把年份、疆域和人的经历，放回同一张地图。

山河行记沿用江山时序的完整地图引擎与历史数据。你可以拖动时间、搜索古城、追随人物生平、编排路线，再切换到同一状态下的三维山河，理解这些事件发生在哪里。

进入作品 ↗打开舆图视角查看能力与操作来源与许可

这是一项基于原库的独立派生作品：复用完整引擎与数据，新增联动三维视角、路线编辑和直接体验入口。核心数据包包含 18 个时期、167 个时期快照和 113 个人物档案。没有接入在线 AI 调用。

原库能力如何落到这件作品里

下面是操作与核对方法。完整 SVG 能力继续由原库控制器执行，三维视角读取同一套状态。

原库能力本作品中的实现如何体验与核对
时间轴与疆域保留年份、朝代、年号、编年事件和阶段快照；三维地图同步疆域。输入前 230 年并向后推进，观察统一进程；切换视角核对年份与疆域。
点地溯源保留古今地名检索、城池沿革、历代归属和当地历史事件。搜索长安，打开沿革卡片；选择一条史事，检查时间轴是否跳转。
点人溯事保留人物搜索与完整生平事件；年份、路线、地图和卡片联动。搜索苏轼或秦始皇，切换上一处 / 下一处，或播放行迹。
同年与跨年路线保留原库路线能力；新增 2–20 站编辑器，验证地名和年份。点击“编路线”。填一个年份或逐站年份；测试未知地名、数量不符及公元 0 年提示，再生成有效路线。
历史 / 现代图层保留疆域、州道政区、古地名、关河丝路、山川和现代省界开关。进入明代，开关现代省界对照。精细政区悬停和透视镜使用 2D 舆图。
古地名寻址挑战保留线索、落针与球面距离评分；进入时自动切为 2D。开始一局，根据线索落针并确认，查看实际位置与距离反馈。
本次新增：同图三维视角真实现代 DEM 地形，叠加历史疆域、城池和人物 / 自定路线。旋转、缩放地图，点击城池或站点；在 2D / 3D 间切换，核对当前年份、人物和路线保持一致。

三维展示的是什么

这里的 3D 是历史地图的另一种视角。15 张公开高程瓦片生成 361 × 253 网格，共 91,333 个采样点，与原库墨卡托投影对齐。Three.js 实时绘制地形、疆域、城市和路线，拖动会真正改变观察角度。

2D 与 3D 共用同一个历史地图控制器。选择人物经历或更改年份，会同时改变当前地图状态；切换视角继续查看这段历史。三维目前用于地形、疆域、城池与路线，精细 SVG 悬停、透视镜和寻址挑战保留在舆图中。

此前的三座微缩场景没有呈现源库的主要能力，已退出主入口。当前作品围绕地图的时间、空间和内容联动组织。

来源、许可与资料边界

  • 完整地图引擎与数据：DeanChensj / jiangshan-map 固定版本 53059f1c7fed；本地保留 54 个上游文件，见 版本、文件与校验清单。历史数据含 18 个时期、167 个时期快照、468 条编年事件、113 个人物档案及 7 条预设旅程。
  • 统计口径：快照对象共 168 个键，其中包含 neighbors；166 个历史快照由阶段显式引用，现代时期隐式使用 s_prc，合计 167 个时期快照。1405 是分时期城池记录总和，不是去重城市数。
  • 历史资料边界：疆域和政区是示意性近似，不是精确测绘。保留上游史料与数据，不宣称逐条重新校勘。可查 上游说明与 校勘约定。
  • 真实高程：Mapzen Terrain Tiles / AWS Open Data；15 张来源瓦片、处理与哈希记录。这是现代 DEM，不是古地貌复原；竖向高度在显示时夸张。
  • Global SRTM / GMTED2010 terrain data courtesy of the U.S. Geological Survey; global ETOPO1 terrain data from U.S. NOAA。高程来源与使用条款。
  • 路线：连线表达人物事件或诗文地点的时空关系，不是精确行路轨迹，也不保证包含途中每个地点。
  • 代码与素材：原库代码 GPL-3.0，新增代码 GPL-3.0-only；上游许可全文。CHGIS V6 / Hartwell 等数据仍受原始学术、非商业条款约束。Three.js 0.180.0 为 MIT，见 许可与 模块清单。代码许可不会改变素材的独立条款。
