# J1 静音首读（仅看2fps拼版，先X后Y；未读任务与标准）

## X
这是一个把收藏的开源项目转为理解与研究的工具/研究集。以 Kokoro 的“文字怎么变成声音”作为问题，进入研究笔记，先把原理拆成文字转音素、预测时长与韵律、解码为波形，然后对照 GitHub 源码查证，最后做一个小实验并记下错误。结尾指向 GitHub 项目研究集及仓库地址。
不理解或拿不准：小实验具体输入、输出和错误记录的小字在拼版中读不清，不能准确复述实验做了什么；开头卡片到界面的放大过程中有几帧近乎空白，可能是转场。整体能看出三步研究路径，更多像分段展示。

## Y
从“收藏之后，下一步？”出发，点击 Kokoro 卡片进入研究界面，先看文字如何变声的三段原理，再看到可调音高波形的演示，然后查看源码来源，最后验证数字朗读是否正确并记录错误与遗漏，结尾给出研究集和仓库地址。核心是收藏、理解、验证。
不理解或拿不准：波形演示与 Kokoro 的实际运行结果是否相同，画面只凭拼版无法确认；实验结果似乎是“待填写”，看上去是研究入口而非完成的评测。底部阶段短线有导航/进度意味，但小字很小。
