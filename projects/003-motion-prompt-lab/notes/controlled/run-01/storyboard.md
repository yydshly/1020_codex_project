# 制作 brief

mode: product。主题：GitHub 项目研究集的 Kokoro 学习路径。观众：收藏了开源工具、想弄懂原理的开发者。结尾：知道可以沿着原理、来源与小实验继续研究，并记住仓库地址。规格：20秒、1280×720、60fps。工具：Node + @napi-rs/canvas、Python、FFmpeg。声音：原创合成配乐与较低音量事件音，无旁白。自主制作。

## 方向与选择
1. 一张研究卡：收藏卡展开为原理、来源与实验表，始终保留 Kokoro 标题。选择此方向，物体与信息有明确延续。
2. 一条声音路径：以音素成为波形为中心；容易误导为实际合成结果，舍弃为主线。
3. 一本实验日志：强调填写与证据，但第一秒缺少产品入口，舍弃。

标志性瞬间：收藏中的 Kokoro 卡展开为可读的真实产品页面；原理节点把注意力交给教学波形；同一张卡在结尾留下实验问题而非伪造成功结果。

## 风格手册
六色：纸 #f6f5f0、白 #fffefa、墨 #263b34、绿 #255746、浅绿 #e7ede3、陶土 #ac573b。正文一律使用深墨或绿，不沿用对比度偏弱的 muted 色。字体固定 shared/fonts/msyh.ttc、segoeui.ttf。favicon 直接读取原 SVG，不另画官方标志。纸面、细边、圆角、有限柔影。缓动为五次 smootherstep 与轻微跟随；主卡贯穿，不使用无关粒子。界面按真实 UI 重建，各组件可动；为 720p 产品展示适度删减文本。

## 参考研究
只读取 shared/reference.mp4。已抽取每3秒缩略图并用 FFmpeg scene 差分筛选剪辑点。观察原则：用真实功能操作维持信息连续；大景别与局部交替；让界面成为主体，留出阅读时间。未使用参考片任何画面或音频作为素材。参考中的3D倾斜并非本片叙事必需，不复制其版式。更多密集抽样将在证据目录保留。
