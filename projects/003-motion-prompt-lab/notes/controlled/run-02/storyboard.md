# 分镜 v1
20 秒 / 120 BPM / 60 fps。原产品的纸色、松绿、铁锈橙，原创配乐。
贯穿物：Kokoro 研究卡的橙色定位签。由收藏卡上的标记展开为页面活动导航，变为原理流程的进度线、来源引用边线、实验记录栏，最后回到研究集书签图标。
0–3 秒：第一帧完整，大字“收藏之后，怎么真正弄懂？”左侧，两张浅色研究卡右侧；Kokoro 卡向前移动且其余卡退后，定位签延伸引出下一场。
3–5 秒：拉近到重建的产品 UI，侧栏“工具研究笔记”、Kokoro 主标题、文稿+语言+音色→语音；标题“从 Kokoro 开始”。Kokoro 的活动项随镜头进入底层原理。
5–9 秒：UI 的流程面板放大为三段可读组件：文字转音素 → 预测时长与韵律 → 解码为波形。橙色定位线连续经过各阶段。波形标“教学示意 · 非模型运行”。上方“01 看懂原理”。
9–12.5 秒：波形线的端点收束为来源卡的引用边线，显示“02 每一步，都能追到来源”、hexgrad/kokoro、commit dfb907a、pipeline.py / model.py。链接和固定版本信息真实；不展示虚构代码。
12.5–16.5 秒：引用卡翻开成实验记录，标题“03 用一个小实验继续研究”，展示中英文短文、专有名词与数字、错读/生成秒数/音频秒数/设备，结果明确“待实测”。右侧样本卡进入记录格但无勾选成功。底部“每次只验证一个问题”。
16.5–20 秒：研究卡收束到品牌区，展示三步“理解原理 → 查看来源 → 验证小实验”；品牌“GitHub 项目研究集”与 URL github.com/yydshly/1020_codex_project，大字持续可读至结尾。定位签线在整个收束过程中保持连接，最终成为原 favicon 三条线。
运动：优先内容推动的拉近、面板分解、行列重排和连续标记。柔和曲线，快速移动使用多时间采样的轻微运动模糊。阅读段采用缓慢有方向的构图运动，避免无意义闪烁。
音频：原创 120 BPM，20 秒共 40 拍；关键分段 3,5,9,12.5,16.5 秒均为半秒整数拍。音效与音乐独立轨，音效低于音乐。最终混音测 LUFS/真峰值。
