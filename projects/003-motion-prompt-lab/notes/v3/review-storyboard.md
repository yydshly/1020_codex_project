# V3 独立分镜评审

结论：**再改一轮**

## 审查范围与证据边界

完整读取原提示词，以及本轮 brief-input.md、brief.md、facts.json、storyboard.md、style-guide.md；未读取其他版本或制作过程。当前只有文字分镜，没有实际视频或风格帧，因此下面是制作可执行性评审，不是成片抽帧评审。不能据此宣称静音故事、品牌准确、文字对比度、像素交接或参考级视觉质量已经通过。facts.json 内部对应关系可以检查，源文件原句、哈希与实际页面真实性本次未独立复核。

故事骨架成立：进入研究集 → 选择工具 → 读原理和教学示意 → 看待实测记录及来源 → 前往仓库。20秒、60fps、1200帧和八个2.5秒场景的算术一致。没有编造工具性能、用户评价或实测成功结果。以下问题仍应在正式制作前改掉。

## 必修问题

### P1 · 操作和结果顺序含混，可能拍成先换页再点击

- **300–449帧（5–7.5秒）**：场景已经是“Kokoro原理页特写”，325帧才“按原理页入口”。若按文字直接实现，入口操作发生时结果已存在。应明确入口来自上一场还是本场；锁定点击前保留的UI、点击帧、第一次结果可见帧，以及完整因果可读的起止帧。
- **600–749帧（10–12.5秒）**：场景先定义为实验记录，625帧才点击“实验记录”。改成前25帧保留可点击导航与上一状态，625帧点击后再出现记录；或把操作提前至上一场，保证结果首次出现晚于操作。
- **750–899帧（12.5–15秒）**：“775帧打开来源”仅对应两张写着“官方来源”“固定版本”的卡。分类标签不是已打开来源的可见结果。至少展示一条真实来源的可识别标题和固定版本标识，或改为如实描述的“选中来源卡并展开摘要”，避免假装已打开外链。新增画面文字须补入facts.json。

原文要求“每个操作都有看得见的结果”。不能以点击音或卡片高亮替代打开页面、切换内容的实际结果。

### P1 · 四种交接叙述互相竞争，尚无可验证的像素合同

**149/150、299/300、449/450、599/600、749/750、899/900、1049/1050帧附近**：总则要求同一纸签每次在(640,360)覆盖全屏；分镜又写Kokoro卡片展开、输出框接下镜、波形线变表格、两页合拢。没有说明这些物体与纸签何时合一，容易执行成场景之间重复插入的绿色遮幕。

只规定中心相同不能证明“同一组像素”：还需每次交接的轮廓或边界、宽高、角度、运动方向、颜色，以及交接前后对应帧。修改分镜，逐个选定唯一接力物，画出/写出至少交接前、交接点、交接后三个状态。允许贯穿纸签改变功能，但不要让它每2.5秒都用同一种全屏开合掩盖场景关系。

“边界前后完全覆盖画面”也需给出具体持续帧数：大面积纯色若无可见细节运动，所谓纸签仍在变形可能在输出像素中已冻结。此项只能在成片测量。

### P1 · 阅读窗口尚未扣除转场和逐项出现时间

- **300–449帧**：文稿、音色、语音逐节点出现，另外有Kokoro/场景标题；目前没有完整关系停留多久的定义。
- **600–749帧**：三个英文工具名、三处“待实测”、导航和边界说明可能争抢2.5秒。建议用Kokoro单行作为主证据，其余行弱化为背景；明确核心内容至少42帧完全可读，较长语句按实际词组增加时间。
- **900–1049帧**：925帧后才展开三个步骤，后面还要离场，必须定义最后一步出现后整个路径的阅读窗口。“运行验证 → 改造实践”要明确是研究路径，而非此次已完成记录；“研究中”应与路径同时可见，避免只在角落或转场中一闪。
- **1050–1199帧**：“保持至少2秒可读”意味着完整名称和网址最晚在1080帧稳定可读，且一直保留至1199帧。上一场全屏纸签展开不能占用超过这个窗口。请将这个约束写入分镜，而不只写意图。

必须区分“画面存在”与“可读”：字在遮罩、缩放、快速移动中不能算完整阅读停留。20像素只是字号下限，不等于720p最终编码后来源文字可读。

### P2 · 首帧能解释类别，但钩子的视觉机制还没有确定

**0–59帧**：“GitHub 项目研究集 + 理解原理 + 目录纸签”具备信息，却仍是常见标题海报。没有规定用户一眼能识别的产品实物细节，也没有明确首秒中何种变化让“收藏后继续研究”成为有吸引力的行动。保留完成的首帧，令纸签上出现可辨识的真实工具条目或原理结构，并让首秒动作直接引导进入该条目。不要用增加口号补偿画面内容不足。

### P2 · 教学示意必须与动作同步可读，且不能伪装真实测量

**450–599帧（7.5–10秒）**：475帧移动控件、波幅增大的因果是可执行的亮点。但“教学示意”应在波形首次出现前或同帧出现，整个操作与结果期间保持可读；控件前后位置、波幅前后值和结果开始帧应明确。波形不应给出未经来源支持的质量、速度、音量单位或实测数据。

## 事实、品牌与静音检查

- 分镜列出的主要名称、流程、状态、网址，在facts.json中都有对应条目。该结论是清单内部检查，不是原始资料真实性核验。
- brief将贯穿物写为标着“研究”的纸签，但facts.json只有“研”和“研究总览”等条目。若确实显示独立“研究”，需登记它作为来源词组的编辑性缩写，或使用已登记文字；不要把分镜里的描述性名称自动变成上屏文字。
- “官方来源”“固定版本”只可作为已有资料的属性，不足以替代实际证据卡内容。
- 使用真实网页“研”字组件和原始favicon符合目前品牌方向。分镜未说明它们在成片中的具体位置与使用方式，正式素材需保持原始资产或组件形态，不能自行画一个近似图标并称为原logo。
- 静音故事按文本可以复述，但第05–07场容易连续变成“读表、读卡、读三步”的文字说明。修订应优先让选中、展开、状态落定和访问入口承担信息；最终仍需独立评审只看无声2fps拼版复述。

## 构图节奏与质量风险

八个名义构图均为150帧，满足product的84–210帧范围；但这是时间表通过，不能认定实际构图变化通过。需要以视觉重心、景别、主体占比和空间组织判断，不能把相同卡片模板换文字计为新构图。

第02、03、05、06、07场大多以矩形信息面板为主体；第05场的“俯看式”与第06场“双栏”尚不足以证明版式不重复。建议在修订分镜中为每场补一句明确的主构图和主体占比，例如目录全景、单个输入输出结构特写、状态标记局部与证据页纵向展开，并让这些差异服务同一张研究卡的旅程。

当前最显著的平庸风险是：规律的2.5秒翻页、反复中心遮幕、正文卡片依次进场。它可能成为清楚的说明演示，但仅靠“纸张质感、呼吸、弹簧”不能证明达到参考作品水准。先解决操作因果和转场关系，再用实际3–5秒测试段判断读字、速度、材质、运动模糊与声音。

## 进入制作的条件

修订分镜，补全上述操作先后、七次交接状态和核心文字窗口；来源操作给出具体结果，末屏锁定1080帧前完整可读。随后进行原文要求的3–5秒完整测试。对比度、品牌像素、冻结时长、音画误差、混音及参考级观感全部保留为待实测，不能由本报告代签。
