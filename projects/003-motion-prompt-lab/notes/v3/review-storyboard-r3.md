# V3 分镜与风格帧独立评审 R3

结论：**可以进入制作**。

这是分镜与三张静态风格帧的制作前评审，不是成片评审，不代表可以发布，不预签实际视频测量或参考级质量。此次由全新评审独立执行；没有读取制作代码、其他制作过程、旧评审或 V1/V2。只读了下列十个指定文件，原提示词全文已读。

## 判定口径

按原提示词、brief-input 的明确输入及声音冲突处理评审。分镜内以最新 R3 对 f685 的主次、重复标签与尺寸约束为准；R2 的连续 favicon 交接合同覆盖初表“展开遮幕”等描述；R1 的操作因果与可读窗口覆盖初表含混操作。初表仅作概览，不能反向恢复已取消的全屏遮幕、325 帧重复打开原理页、775 帧假装打开网页等行为。

## 评审发现（按严重程度）

### P2 · 制作时必须修正：指针与文字发生局部遮挡

- `style-3.png` / f685 / 11.417 秒：指针落在左列 Kokoro 字尾上，白色轮廓与最后字符相交。状态文字和整体含义仍可辨认，未破坏分镜结构，但不符合最终“没有元素打架”的要求。
- `style-2.png` / f365 / 6.083 秒：指针紧贴“文稿”下缘，静态可读，运动期间仍有擦过字形的风险。
- 制作要求：点击完成后将指针停靠到按钮留白区；保持实际点击对象和结果清楚，不要为避让而让指针失去指向。成片需抽查点击、离开、完整阅读窗口，不能仅修这两张截图。

### P2 · 首帧视觉语义需收口

- `style-1.png` / f0：目录右下的纯纸色圆角小块没有标签或可识别操作意义。主画面本身已经完成，名称、用途、真实工具名与研究状态清楚；但该小块目前像未完成的控件，也不在文字分镜中承担清楚的动作结果。
- 制作要求：若它是动作主体，必须在首秒用动作说明其功能；否则移除。此项可以在正式组件制作时处理，不需要重新选择创意方向。

### P2 · 交接合同可执行，但仍须完整实现与测量

- 八个锚点、统一 80×80 尺寸、前后各 18 帧连续采样、禁止全屏遮幕均已给出。它比初稿概览更具体，足以交接制作。
- 原文要求由内容本身完成转场。持续移动的 favicon 只能提供主体连续性；若周围 UI 只是统一淡出淡入，仍可能成为重复的装饰性接力。七次转场必须让目录选择、节点关系、波形、记录与来源之间的内容变化可理解。
- 风格帧没有覆盖任何交接中点，不能据此认定像素连续、出入场安全、运动模糊或转场自然。尤其上拱 100px 与最大 1.3 倍缩放需要逐帧检查上边缘及文字避让。请保留真实轮廓和一套位置函数，不用背景遮挡掩盖不连续。

以上问题均可在制作中直接修正，没有要求重做分镜方向的 P0/P1 阻塞项。进入制作不等于这些问题被豁免；场景与完整成片独立评审仍须复查。

## 已核对内容

- **任务匹配与节奏**：product 模式、20 秒、60fps、1200 帧、1280×720；八个场景每 150 帧换构图，即每 2.5 秒，位于原文 product 的 1.4–3.5 秒区间。场景边界按 `[start_frame,end_frame)` 理解，与分镜 0–149 等包含端点表述一致。
- **首帧与版式**：首帧具备完整海报构图，名称、用途、研究状态与真实工具条目同时出现。三张风格帧有大字海报、节点 UI、记录表三种明确构图。仅三帧不足以认定八镜均不重复。
- **R3 主次与重复标记**：f685 左列“待实测”明显大于另外两列；右下仅见一个原 SVG 形状接力图标，没有第二个自建“研”标签。f365 导航内“研”与外部 favicon 各有不同语义，没有相互重叠。
- **文字与事实映射**：三张图可见的名称、工具名、研究状态、导航、因果文字、记录边界均能在 facts.json 找到对应 `screen_text` 或明确组成项。分镜后续所用“教学示意”、真实仓库名、commit 前 12 位及落版网址也已列入 facts.json。事实表没有提出安装完成、性能、价格、用户评价或自动集成结果。
- **核实边界**：本次按限定范围核对的是画面与 facts.json 的映射、引用结构及内部一致性；未打开 facts.json 所引用的仓库原文件或链接，不能将其写成独立源头事实核查通过。
- **动作因果**：225、325、475、625、775、925 帧已有触发、后续结果和阅读窗口。775 帧明确为展开来源摘要，避免伪造外部网页打开；研究路径没有完成勾选，有助于避免“全部已运行”的误解。
- **阅读窗口**：完整原理关系 372–432 帧约 1.02 秒；主要实验记录 660–732 帧约 1.22 秒；来源 810–882 帧约 1.22 秒；回顾 950–1032 帧约 1.38 秒；落版 1074–1199 帧为 2.10 秒。计划均超过 0.7 秒最低值，原理三个语义节点也超过约 0.9 秒。实际字体呈现、源信息密度及网址可读性仍需视频确认。
- **静态尺寸**：实际读取的三张 PNG 都是 1280×720。视觉检查未见文字超出规定安全区；未做逐字像素包围盒测量，不据此签署全片安全区通过。
- **配色与对比**：从 PNG 主色像素确认纸白 `(246,245,240)`、深绿 `(30,75,64)`、墨色 `(38,59,52)`、纯纸 `(255,254,250)`，f685 也确认赭色 `(172,87,59)`。按 sRGB 相对亮度计算：赭/纸白 4.602:1，赭/纯纸 4.978:1，墨/纸白 10.946:1，纯纸/深绿 9.744:1。所列实色文字搭配达到 4.5:1；半透明、运动混合帧及所有其他组合未因此获批。
- **静音叙事预期**：研究集用真实工具做原理说明，展示待实测记录与来源证据，最后给出仓库入口。该逻辑在分镜上成立。没有拿成片无声每秒两帧拼版做复述，本项仅是分镜理解。
- **时间轴**：48 个节拍按 25 帧排列，与 60fps/144BPM 一致；场景边界和列出的点击全部落在这些节拍上。timing.json 自报 PCM 检测误差 0 帧；本次没有读取音频，故未独立验证检测结果、响度、真峰值或音效相对音量。

## 后续评审保留项

正式全片制作前仍须按原文完整渲染 3–5 秒测试；本次未读取测试，因此不认定已完成。声音先行、原创音乐、字体本地固定、真实素材采集与参考研究均仅见计划或说明，未在本次限定输入中独立验真。

场景完成与完整渲染后，需要全新评审实际抽帧与测量：每 0.2 秒采样、转场加密、冻结时长、字形与指针重叠、安全区、品牌色、交接像素轨迹、动作与音频 ±1 帧同步、LUFS/真峰值与音效相对音乐。完整渲染还要做无声拼版复述、源头事实核查、与参考并排的导演审片，以及 ledger 的修改前后数据记录。

此次未看参考作品，不作“参考级质量已达到”的判断。当前风格方向整洁、产品阅读关系明确，但其动势、转场惊喜和整体完成度仍需作品本身证明。
