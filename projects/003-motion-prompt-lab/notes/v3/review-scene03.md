# V3 场景 03 独立评审

结论：**再改一轮**。

评审对象：`web/media/v3/scene03.mp4`，全局帧 300–449（5.000–7.483 秒），150 帧，片段长度 2.500 秒。SHA-256：`eb6ae9a60323a378b7f49063545d4affc7e76c4b899f9509b5254c83eb1bc62b`。

## 独立性与方法

本评审只读取原提示词全文、`notes/v3/brief-input.md`、`facts.json`、`timing.json`、指定实际场景视频和指定 Linear 参考视频/拼版。没有读取制作代码、旧评审或 V1/V2。

用 FFmpeg 从实际 MP4 独立解码全部 150 帧，再从这些实帧建立每 0.2 秒（每 12 帧）拼版；头部每 3 帧、点击附近 320–333 每帧、尾部每 2 帧加密。实际看了这些拼版、无声 2fps 拼版、全局 360 原大帧、点击裁切，以及 Linear 参考密集拼版和从参考 MP4 独立抽出的 12.5 秒原大帧。帧号均为全局零基帧号，局部帧号加 300。

## 按严重程度排列的问题

1. **P1 / 363–416 帧（6.050–6.933 秒）：近冻结超过硬性标准。** FFmpeg `freezedetect=n=-60dB:d=0.5` 检出局部 1.050 秒至 1.933333 秒，持续 0.883333 秒。所有相邻帧并非逐像素相同（零个完全重复帧），但微小呼吸/编码变化不足以通过这个明确写出的检测阈值。0.883333 秒超过“任何静止段不超过 0.5 秒”。肉眼拼版也支持：三块完成后长时间没有新的信息、可辨识状态或运动。可修：让有叙事意义的连接/输出变化继续发生，或重新分配进入和结果的时长；不能只添加无关微动来满足数字。

2. **P1 / 325–432 帧（5.417–7.200 秒）：操作结果过于概念化，未达到参考作品的产品演示强度。** 光标一直贴在“文稿”文字附近；点击后“音色”“语音”顺次淡入，但没有具体输入、可识别的控件状态变化或可检查的结果。观众看到的是公式的出现，难以区分真实操作和讲解图。静音能懂“文稿加音色得到语音”，却无法知道研究集在这里让用户实际做了什么。参考中可以读到输入请求，以及随之出现的具体回答/列表；本段目前更像静态教程卡片的渐显。可修：依据已有真实页面/事实素材选择一个清晰操作，让按压状态和结果区域直接呼应；若仅为教学图，明确其教学性质，做出输入到输出的因果运动，避免暗示已运行生成。不要为加强演示编造实测输出。

3. **P2 / 300–315 与 432–449 帧（5.000–5.250、7.200–7.483 秒）：转场由整体淡入淡出主导，贯穿图标没有承担内容交接。** 首帧只有左上方小图标和大面积浅底；尾帧也只剩漂移图标。图标没有展开成面板，面板也没有收拢回图标，而是独立改变透明度。最后的拖影能感到速度，但主体的退出缺乏内容上的理由。该问题不等于把本段首帧误当成全片第一帧；它是在评价段内可见的转场半边。可修：让图标或已存在的“文稿”节点接管遮罩/面板边界，让主体位置和形状发生有依据的接力。前后场景未提供，因此边界同像素连续性为 UNVERIFIED。

4. **P2 / 315–432 帧（5.250–7.200 秒）：信息层级重复，空间利用与镜头发展偏平。** 上方“文稿 + 音色 → 语音”已完整预告下方三块，再加第二个 Kokoro 标题、侧栏、左侧悬浮图标和页脚。主信息只是一条公式，却被安放在多个重复标识之间。整个阅读期的景别基本不变。画面干净而且可读，但没有足够的视觉选择来与参考的紧密构图、焦点迁移和产品结果并列。可修：删去一个重复层，放大真正承担动作的内容，把注意力从输入明确移到输出；不必模仿参考的深色或 3D 风格。

## 点击与同步

`timing.json` 声明 click-1 在全局 325 帧。密集实帧中 325 附近“文稿”块有轻微尺寸变化，后续 327 帧“音色”开始可见，之后“语音”出现；因此存在动作后的视觉结果。按压读感很弱，光标没有清晰可读的点击标记。由于混合 AAC 轨中未独立分离点击瞬态，也没有可靠测得可见按压起点，本报告**不宣称音画 ±1 帧通过，也不把结果在 327 出现直接判为同步违例**。精确音画同步为 UNVERIFIED。场景边界 300/450 在 timing 中均为节拍，但缺少相邻实际画面，完整转场是否卡拍同样 UNVERIFIED。

## 静音故事与事实

只看无声 2fps 拼版，我读到：一张研究页面出现，主题是 Kokoro；文稿与音色相加，产物是语音；页面随后消失，图标继续移动。这能说明一个因果，但不充分展示研究集本身提供的独特操作价值。

可见文字逐项对照 facts：Kokoro（kokoro）、文稿 + 音色 → 语音（process）、文稿/音色/语音（text/voice/speech）、声音基础（sound）、研究总览/能力对照/实验记录（nav1/2/3）、研（brand）、GitHub 项目研究集（title）。均有对应条目。未见价格、性能、评价或实测数字；本段没有波形。**事实清单匹配 PASS**。本评审按授权资料边界未打开底层来源文件，因此源文件哈希/引文真实性复核 UNVERIFIED。没有把未核实来源当作新事实。

## 可修问题与工具/能力限制

可修：近冻结、弱按压反馈、概念公式缺少具体因果表现、整体透明度转场、重复信息层级。这些不应归咎于工具限制。

限制/未核实：只有 2.5 秒单场景，无法验证整片第一帧、全片构图变化、相邻交接像素和完整故事；未做实时人耳试听，声音审美、音效相对音乐响度与逐事件同步未通过；没有分轨，不能证明音效低于音乐；来源色值与源文件内容未开放给本次审片，不能证明品牌色精确或所有来源哈希有效。上述均为 UNVERIFIED，不记 PASS。
