## 按严重性排列的问题

### P1 — f685 / 11.417秒：两个品牌标记发生遮挡

第三张图右下角同时存在横向底板上的“研”和前方竖向“研”纸签。前者文字被后者截断，约发生在 x=1000..1140、y=497..583 区域。它不是有明确上下文的双重导航标记，而是一个完整品牌签压住另一个残缺文字；观众会看到叠错的组件。违反原文“没有元素打架”，且这正是 f660–732 的主要可读窗口，不能作为快速运动中的偶发遮挡处理。

修改：在这一镜只保留一个承担交接的品牌主体，或让底板与纸签合并为一个完整且不裁字的组件。重新提供 f685 及该窗口首尾帧。不得用全屏覆盖隐藏问题。

### P2 — 七次交接 / f132–168、282–318、432–468、582–618、732–768、882–918、1032–1068：主体规格不一致

分镜 R2 明定基础尺寸 78×86、中途放大至1.3倍；风格手册则写同一原始 favicon 始终为80×80。timing.json 记载位置、弧高和半程18帧，却没有基础尺寸与放大倍率，不能解决这一矛盾。七次边界中心分别为 f150/300/450/600/750/900/1050。

修改：统一原始 SVG 的实际几何比例、外部容器尺寸和峰值倍率，并将数值写进 timing.json。若78×86是纸签容器、80×80是内部图标，需要明确二者关系与哪个轮廓在边界保持连续。该项是执行歧义，不代表已测得成片跳变。

### P2 — f685 / 11.417秒，对应 f660–732：主次关系与分镜约束不符

R1要求主要“Kokoro / 待实测”完整可读，另外两条降低视觉权重。实际风格帧中的三个工具列、三个“待实测”、三个“研究中”几乎完全等权。这使单张研究卡的叙事在此变成三栏信息展板，而且重复“研究中”没有增加边界解释。

修改：使 Kokoro 明显成为主列，其他两列保留真实内容但降低尺度或强调程度；也可修改分镜，明确改用三项共同状态作为本镜重点并解释其与持续主体的关系。文字仍须维持4.5:1，不能单靠降低文字透明度处理。

## 已具备的制作基础

- f0是完成画面，标题、用途、真实工具条目都已出现；第一秒钩子具备静态基础。
- 225、325、475、625、775、925帧的操作均写出了随后发生的可见结果。特别是“展开来源摘要”避免把静态资料误称为打开真实网页。
- 2.5秒构图节奏位于 product 模式要求内；八镜具有目录、节点、波形、记录、来源、回顾和落版的不同功能。
- “教学示意”“待实测”“研究中”的计划位置保留了事实边界；最终完整网址计划在1074–1199保持126帧，满足至少2秒的落版计划。
- 在三张图中，主要文字没有明显越出安全区；深绿、墨色及赭色有清楚层级。实际赭色 #ac573b 对纸白 #f6f5f0 的计算对比度约4.60:1，对纯纸 #fffefa 约4.98:1，达到原文阈值。该结果只覆盖这些实色组合，并非全片文字对比度验收。
- 核心屏幕文案可以在本次 facts.json 找到对应条目；未发现虚构性能、安装完成或商业成绩文案。没有访问原始事实文件，因此本评审不把来源真实性复核记为完成。

## 制作后必须另验，不能现在签字

R2取消全屏遮幕是合理方向，但纸签沿弧线飞过、周围UI退场，是否真正由内容完成转场，仅凭文字和三张静帧无法确认。应在每个边界 B−18..B+18 密集抽帧，检查同一主体轮廓、位置连续性、层级遮挡，以及上镜实际内容怎样变为下镜内容。不能以“同一个品牌图标还在”代替内容转场质量。

同理，实际文字停留、运动模糊、呼吸是否构成冻结、操作与声音误差、响度、音效相对音量、原品牌色、静音故事复述及参考作品同台质量，均尚未验收。timing.json里的PCM检测零误差不等于图像同步零误差。本评审也没有听音频或查看参考作品，不能对此给通过结论。

最小返修范围：消除f685品牌遮挡，统一交接几何规格，落实实验记录的主次关系；无需重写已成立的产品故事。
