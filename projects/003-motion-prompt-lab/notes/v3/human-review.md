# V3 人工待核事项

本实验通过程序实际播放了音频，但当前制作与评审接口没有提供可由模型可靠主观听辨的输入。设备播放成功、波形或响度测量，不等于亲耳听过。以下项目未由这些技术记录自动签署：

- 用正常音量的耳机和扬声器听完整片、纯音乐：旋律是否适合研究工具主题，音效是否可闻但不抢音乐，结尾是否自然，是否存在刺耳或疲劳感。
- 看着真实画面逐个听换场和操作音效：最终AAC的弱音效起点/能量峰是否自然贴合动作。PCM分轨误差和整体AAC互相关只能证明各自的测量范围。
- 在浏览器全屏及小尺寸观看所有文字：特别是快速交接、显现中的半透明笔画、中文/英文字形、网址以及指针靠近文字时的可读性。稳定帧抽检不能证明全1200帧所有字形≥4.5:1。
- 对照真实研究页确认演示边界：“教学示意”“待实测”“研究中”是否足够醒目，观众是否误以为Kokoro已实际运行或来源按钮真实访问了外部网页。
- 将影片与实际官方参考并列观看，评价节奏、内容交接、文字表现和最后两秒的阅读体验。机器冻结阈值与语义导演判断分开保留。
- 如品牌有严格RGB像素要求，检查编码后的色彩容差。当前浏览器常用H.264/YUV420编码会引入色度取样和量化偏差；不得把接近源色写成逐像素完全相同。

未核项不是默认通过，也不是对原文标准的豁免。最终逐条状态、对应影片SHA和独立评审结论以quality.json与ledger.md为准。
