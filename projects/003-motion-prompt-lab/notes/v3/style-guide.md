# V3 风格手册

六色上限：纸白 `#f6f5f0`、纯纸 `#fffefa`、墨 `#263b34`、源favicon绿 `#1e4b40`、源favicon纸色 `#eee9dc`、赭 `#ac573b`。来自真实产品 styles.css 与 index.html 原始favicon SVG；将两种绿色合并到源favicon绿，避免实际logo带来第七/八色。透明度用于阴影而非新品牌色。

本地固定字体：真实页面的 Segoe UI / Microsoft YaHei，分别从本机 segoeui.ttf 与 msyh.ttc 固定至私有 `.cache/v3-source/fonts/`，字体SHA在asset manifest。仅渲染栅格视频，不向网页分发系统字体。初始风格帧曾用Noto替代；评审前已重渲染为真实字体，记录这次改正。

材质：轻薄纸页、细规则线、有限投影；不使用装饰粒子与素材库故障。实色背景以文字对比度≥4.5:1为目标，最终编码实帧另测，不能从色值配置推定全部通过。安全区：x=64..1216，y=48..672；转场离场文字的瞬时越界与稳定阅读期分开报告。

字号：海报主词132；场景题42–58；UI正文22–32；来源/边界不低于20；最终名称64、网址31；不在高速运动时承载新信息。

动效语汇：真实favicon保持位置连续；非线性进出、依次展开；次级动作错开10–12帧。部分阅读镜头使用5像素/180帧呼吸；回顾以路径连接逐渐完成，落版以网址下划线完成而非随机漂移。快速离场使用三子帧积累运动模糊。

交接：原样解码的 source-favicon.svg始终可见，以80×80源尺寸沿timing.json八个锚点弧线连接，中段有1.3倍伸展。它属于002研究页而非GitHub官方。R1七次缩页被独立评审退回；R2仅保留第1/6处，其他交接分别由卡片、语音波形、翻页记录、Kokoro来源卡和路径线承担。没有全屏遮幕。要实际抽帧验证，不能仅凭代码标记通过。

前期三张风格帧在帧0、365、685渲染并接受分镜评审，保留其历史版本；不是最终影片截图。最终poster与contact-sheet必须从最终MP4解码提取。参考来源与分析在 references.md。原文要求品牌色准确；H.264 YUV420有色度取样和压缩误差，不将“近似正确”改写为“完全准确”。
