# V2 分镜独立审查

日期：2026-10-20  
审查依据：`v2-brief.md`、`facts.json`。未读取实现代码，也未观看尚未提供的样片。本审查只能判断分镜风险，不能确认实际动效已连续或文字已可读。

**结论：先修改分镜，再进入四秒样片。** 主叙事可以成立，但当前“声波变来源文件”存在因果误读；“同一个对象”的具体视觉锚点与每镜实际文字尚未锁定。直接制作会把这些设计缺口推迟到动画阶段。

## 必须在样片前修正

## 建议锁定的阅读节奏

20秒不能同时承担完整六工具目录、Kokoro操作演示、三类文件解释与项目介绍。主线应保持为“收藏成为研究档案→看懂一个工具的原理→回到可追溯的研究材料→打开研究集”。

| 时间 | 唯一主要阅读任务 | 辅助信息与稳定要求 |
|---|---|---|
| 0–2.5s | 收藏之后，理解开始 | 星形转成002编号签；避免同时出现第二条口号。 |
| 2.5–5s | 六个工具研究 | 002与Kokoro目录行稳定可辨；不要求读完所有目录项。 |
| 5–7.5s | Kokoro | 目标行展开成工作台；“原理示意 · 尚未本机实测”开始持续出现。 |
| 7.5–10s | 文稿 → Kokoro → 语音 | 状态说明持续显示；给完整链路至少约1秒的整体观看时间。 |
| 10–12.5s | 来源可追溯 | 通过研究窗口里的来源入口展开文档，消除“语音生成证据”的因果误读。 |
| 12.5–15s | 尚未本机实测 | 三份材料是并列页签，仅阅读状态说明；不追加第三条口号。 |
| 15–17s | GitHub 项目研究集 | 002档案归位；标题形成，网址准备稳定。 |
| 17–20s | 仓库地址与产品名称 | 地址完整单行、不截断；只保留一次简短行动号召或直接省略。 |

“文字至少0.7秒”只能作为短标签的下限，不能作为中文句子与网址的统一验收标准。建议主要中文信息稳定约2秒；网址从17秒到尾帧完整保持3秒。稳定阅读期内不能随父容器继续缩放、旋转或产生运动模糊。片尾网址建议先按28–32px制作，并通过1280×720实际显示检查；这只是起点，不能替代观看判断。

每镜2–3个声音峰值会使20秒内几乎持续出现重音，削弱动作层级。保留编号形成、档案展开、选择Kokoro、链路输出、来源页展开、归位六类主要声音事件；其余动作用轻声或静默支撑。具体响度仍需样片试听，不能仅凭峰值时间表确认通过。

## 事实边界核对

- F1支持“GitHub 项目研究集”及从理解到实践的方向，但不支持当前所有研究条目已经完成运行验证。开场文案属于原创叙事，不能搭配完成徽章变成实绩声明。
- F3支持002有六个工具，并包含Kokoro。此次只讲一个工具是合理取舍，不必为了事实完整塞入六个名字。
- F4要求区分研究与本机实测。状态提示应贴在最可能引起误解的工作台上，不能只靠片尾或后续镜头补充。
- F5列出了研究说明、来源记录、实验计划和Web演示的本地路径。当前分镜可只选前三项；不要将实验计划画成已有实验结果，也不要将来源记录标为测评证明。
- F6支持仓库地址`github.com/yydshly/1020_codex_project`。事实文件明确本地内容可能尚未发布，结尾可引导打开仓库，但不要写“立即体验全部演示”或暗示片中所有本地页面已在线可用。
- `facts.json`中的帧区间沿用已有事实编排，不能直接作为V2的逐帧事实覆盖证明。V2分镜锁定后需要重新对齐：尤其Kokoro原理演示的状态提示、来源材料段与片尾区间。

## 进入样片的条件

1. 将04→05交接改成“返回研究窗口，打开来源记录”，或同样明确的查阅关系，避免输出变成证据。
2. 在分镜中锁定每镜最终文案、目标行数量、橙色002编号签的落点和可见状态；不再使用未定义的“条目”“标题”代替具体内容。
3. 将“原理示意 · 尚未本机实测”固定覆盖03、04，并在主要运动之外留出稳定阅读区。
4. 在时间表中标出主要信息的实际静读段，而非只写统一的0.7秒最低值。

满足以上四项后，可以制作开场四秒样片，检查星形→编号签→档案的识别连续性、中文显示和运动层级。该样片不包含全片风险最高的04→05交接，因此它通过后仍需补做约8.5–13秒的过渡样片，再进入完整渲染。三个风格帧只能检查静态构图与文字大小，不能代替这段连续观看验证。

## 修订后复核与样片准入

复核日期：2026-10-20。本次仅重读修订后的`v2-brief.md`，未读取源代码。

**更新结论：可以进入样片阶段；尚不构成完整制作或成片通过。** 修订已解决分镜层面的主要阻断：声波保持原理图身份并缩回README研究说明，来源记录以独立页面展开；工作台全段携带原理示意与非本机实测提示；002身份签持续存在；新增8.5–13秒桥接样片能够直接检验最易误读的交接。现阶段值得用样片验证，不必继续仅凭文字推演。

准入后的样片检查必须覆盖以下事项：

1. **开场0–4秒：** 不看说明也能把星形、002编号签和档案识别为同一个对象的变化；开场句有实际静读段，不能靠“共出现2秒”替代稳定可读。编号签展开后应保留独立可辨的橙色身份。
2. **桥接8.5–13秒：** 观众应复述为“工具原理图回到研究说明，再查看资料”，而非“语音被保存成来源文件”；声波在缩回过程保留形态，来源页不得在声波终点直接生成正文。README页名与原理图的关系至少有一个可辨的落定状态。
3. **两段共通：** 状态提示不被遮挡、不随主形变模糊；中文与字号以实际720p画面检查；002签不因跨镜头换位置而瞬移。

仍有三项分镜细节未被修订文字完全锁定，但可在样片制作时形成可检查结果：目录实际出现几条及先后顺序、主要文案各自的静读起止时间、声音峰值的主次。新增的“文案固定在渲染源中”只说明存放位置，不能替代审阅者能看到的文案表；完成样片时应把最终文字与稳定区间补回brief。06镜仍写“焦点逐个经过”，实际样片及后续制作应避免要求观众在2.5秒内读完三个页面正文。以上不足不再阻断试做，但未验证之前不得宣称阅读节奏或全片连续性通过。
