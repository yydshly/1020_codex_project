## 视觉

暖白背景、深绿文字、橙色身份牌；六种基础颜色及字体详见完整执行提示词。使用真实 UI 字段的独立 SVG 图层，没有截图面板或第三方影片素材。阴影是低透明度深绿，不增加新的设计色。

代表帧：`web/media/v2/style-108.png`（1.8秒档案）、`style-486.png`（8.1秒原理）、`style-810.png`（13.5秒文件层）。SVG 文件可检查结构，直接在别的设备打开 SVG 可能回退到系统字体；PNG 和视频固定为 Noto 字体。

## 动作的实际实现

| 手法 | 具体应用 |
| --- | --- |
| 路径形变 | 星形与圆角矩形共用96个有序轮廓点 |
| 大小与空间连续 | 卡片边界变窗口；Kokoro行变工作台；工作台收束为模型模块 |
| 预备和挤压 | 星形先向左下蓄势、变扁，再收拢 |
| 超调与回落 | 编号牌旋转先越过落点；工作台展开后略收回；文件归档后整理入位 |
| 弧线 | 光标的路径包含正弦弧度，点击时缩小并出现反馈环 |
| 次级动作 | 目录分层进入；输入条错开；文字在父容器成立后显示 |
| 形状的语义连续 | 声波保持曲线身份回到README插图，不变成来源文字 |
| 多层空间 | 来源、实验页由同一文档背后展开，按序强调后合拢 |
| 真运动模糊 | 半帧快门；一般3样本；快速区间7样本 |

这些是二维几何与投影层次。没有真实三维灯光、材质、角色或物理弹簧求解；超调来自确定性关键帧，不能把“用了超调”写成“已完成物理模拟”。

## 主要阅读区间

时间是制作设计与抽帧核查范围，不代表真实观众阅读实验。

- 开场主句从第一帧即存在，约0–2.1秒位置基本稳定；不是等待空白入场。
- 002目录长标题在约3.8–4.7秒可辨，5秒前主动退出，避免被新面板边缘擦过。它是次级信息；产品价值由开头和片尾承担。
- Kokoro工作台在约5.9–6.5秒显示三段关系，随后让旧文字先退，再出现模型原理图。这个简短预览不承担完整技术解释。
- 原理图约7.7–9.7秒，明确“原理示意，非本机模型实测”；底部状态说明覆盖整个工作台与原理段。
- 约11–12.2秒读取“回到研究说明”，README作为主要文档，波形保留在页内。
- 来源记录与实验计划在展开后从外露页面读取，橙色强调按先后移交；“实验待验证”与画面下方说明保留事实边界。
- 归档时先退出README文字，再显示002档案文字，避免叠字。
- 片尾产品名在17秒完成；完整网址从17秒保持至20秒。文字固定，右侧档案继续小幅整理。

## 声音

原创程序合成，D小调/Bb/F/C和声语汇，120 BPM，48 kHz双声道，无人声。两个音轨：纯音乐、含动作音效的混音。动作起点与时间轴的帧号一致；不是用Kokoro生成的音频。

较明显的展开/收拢音围绕2、3、6、7.5、11、13.5、15.5、16.5秒，较轻的短音沿节拍支持其余动作。最终响度、真峰值从编码MP4解码测量。人耳音质和所有感知峰值的逐帧对应仍未取得独立人工验证。
