## 冲突及不适用项

音效相对音乐的音量要求在来源中有冲突。本项目明确选择：短动作音可以局部突出，音乐保持底层，总混音不削波，并复测响度。这是任务层面的决定，不把两条互相矛盾的要求都写成通过。

本片不含人物对白、真实 3D 物体、照片素材或第二画幅。相应的口型、三维灯光、栅格图分辨率、竖屏版式要求标记不适用，不伪造通过。其余适用的创作要求保留在质量检查中，即使实际没有达到。

## 怎样理解两版比较

V1 与 V2 的主题及视频规格相同，但实现方式、迭代投入和审片力度不同。网页能展示这次迭代确实改变了什么；它不能单独证明“原提示词使模型能力提高了多少”，也不能测定模型的一般能力上限。
