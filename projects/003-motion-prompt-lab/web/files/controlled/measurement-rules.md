# 统一技术测量补充

在制作期间、尚无完整候选可用时固定（2026-10-23）：

- 同一个脚本解码匿名封存 MP4，核实视频 20.000 秒、1280×720、60/1 fps、1200 解码帧。
- `freezedetect=n=-50dB:d=0.5`；完整计入片尾尚未结束的 freeze 区间。累计 ≤ 2/3 秒且最长 ≤ 0.5 秒为此像素指标通过，不等同于语义流畅。
- 音频技术 10 分：响度 −14 ±1 LUFS 得 4 分，真峰值 ≤−1 dBTP 得 3 分，音轨存在且时长 20±0.1 秒得 3 分。分别列项，不用于掩盖视觉问题。原预注册 rubric 已给出这三个分项与权重，本文件仅固定数值容差。
- 声音的审美、音效是否造成遮蔽不能凭响度替代，留为未验证。节拍相位若无法仅从成片独立确认，也记录未验证，不从制作代码反推通过。
- 盲评分为内容 20、运动 25、阅读 20、视觉完成度 15、事实 10，共 90。两位新上下文评审交换顺序，先只看 2 fps 无声拼版复述，再看每 0.2 秒抽帧和密集转场帧。评审不知道组别、提示词、制作过程或耗时。
- 元数据如包含组别或制作时间，匿名副本只作无损 remux 移除标签，音视频码流逐轨 SHA256 对比，禁止重编码修片。原输出与匿名副本各自保留哈希。
- 先保存评分并算 SHA256，再揭盲。两位同方向且均值差至少 5/90 才描述“本次有方向性优势”；否则为“没有明确优势”。不做显著性推断。
