# 外部盲评操作约定

每位评审为全新上下文，继承同一模型配置；不向评审提供组别、提示词、生产过程、耗时或内部评审结果。第一位按 X→Y，第二位按 Y→X。

1. 只看各匿名影片的 2 fps 无声拼版，先单独写下故事复述和不理解之处，保存之后再继续。不得从任务说明补全自己没看懂的内容。
2. 读取共同任务、统一 rubric 与真实产品资料；实际查看每 0.2 秒帧和完整尺寸关键帧；自行密集抽取观察到的每个转场，标明帧号和时间。
3. 对两条影片分别给出五维 90 分评分，每维有证据。盲评不计过程文档、创作动机或“遵守某提示词程度”。明确指出遮挡、停滞、无意义移动、事实或落版错误。
4. 品质对比须实际查看共享参考片的抽帧。可用同样的技术测量记录，但不能用低运动数字替代动效判断。没有可靠听音能力就不评价听感。
5. 输出原始 Markdown 报告与 JSON；所有评分固定保存后计算 SHA256，随后协调员才能将条件和耗时合并。原报告不可在揭盲后改分。

这是同一模型系列的两次独立评审，不是两位独立人类观众，也不是两个制作样本。候选影片和评审次数分开计数。
