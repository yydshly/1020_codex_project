# V2 产品动效参考：已抽帧核查

核查时间：2026-10-20。目的：为 20 秒产品片建立连续主体、变形、镜头与节拍的可执行依据。以下是从官方页面取得的公开视频片段的实际视觉观察，不是依据工作室名气推测质量。

- 元数据：640×360，30 fps，5.2 秒。
- 已查看抽帧：`.cache/v2-reference/webflow-contact.jpg`，3 fps，从片段起点至约 5 秒，按从左至右、从上至下排列。时间是片段内时间；采样精度约 1/3 秒，不能当成逐帧运动曲线测量。

### 实际观察

| 区间（约） | 可见行为 | 可用原则 |
| --- | --- | --- |
| 0–1.3 秒 | 蓝色 UI 面板旋转；表层、界面层、底层逐步分开，最终形成有透视的水平层栈 | 单一物体变成系统。先保存面板的空间位置和轮廓身份，再展开新含义 |
| 1.3–2.7 秒 | 层栈成为清晰主体，细线和节点沿层间弯曲连接；镜头仍有轻微位移 | 次级信息晚于主体动作进入，视觉上有因果，避免所有层同时抢注意力 |
| 2.7–3.3 秒 | 镜头靠近层栈，随后进入由矩形横条构成的近景 | 将“矩形/层叠”的形状语法保留到下一镜，空间尺度变化提供转场动力 |
| 3.3–5.2 秒 | 近景中矩形条带维持统一透视；球体进入边缘 | 先建立结构，再补充环境细节；画面复杂度是逐步增长的 |

**边界：**抽帧证明了 0–约 3 秒的主体持续与层叠变化；约 3 秒后的镜头切换不能据此说成严格无剪辑的一镜到底，也不能说全片均为连续拓扑变形。这里没有分析音轨，不能声称动作踩中音乐节拍。

### 实际观察

- 过程片段 0–约 0.75 秒：两只手接近中心的小方块，接触发生在尺寸扩张前，动作有明确的预备。
- 约 0.75–1.5 秒：方块向两角撑开，四个角点持续可辨认。观众能理解“大面板是刚才的小方块”，不是凭空换出一张新卡片。
- 约 1.5–3 秒：面板左右倾斜再回到平衡，手的位置跟着角点变化；附属动作受到主动作约束。
- 预览片段中，编辑框扩大后进入丰富的 3D 世界；后半段持续保留中央人物与所在粉色平台，镜头拉远揭示背景。展开世界时保留中心锚点，有助于理解空间连续。

**边界：**过程片段是灰模/过程展示，不代表最终成片的全部材质和节奏。预览本身包含剪辑，不能宣称其场景切换全部是连续变形。没有测量精确 easing 或弹性参数。

## 对 20 秒片的具体应用

以下是本项目的创作推导，不是参考作品的官方制作说明。

1. **指定唯一主物体和身份轨迹。** 主体必须经过“小尺寸核心 → 可操作面板 → 展开的结构 → 汇聚后的品牌轮廓”，位置、边缘或识别标记至少保留一个。不能把每段当独立页面入场。
2. **为每次变形写明起点与终点的对应关系。** 例如面板边框的左右边延展为连接轨迹；角点成为节点；面板内已有条目展开为结构层。跨场用同一组几何实例插值，不用整屏透明度交叉替代。
3. **动作具备前因后果。** 约 0.15–0.25 秒轻微蓄势，约 0.45–0.8 秒主变化，约 0.3–0.5 秒缓冲；节点、纹理、文字比主要形变延后约 0.08–0.18 秒。这些是拟定制作值，并非从参考视频测出的参数。
4. **镜头承担一次主要任务。** 物体变形时保持中心锚点；结构形成后再推进、侧移或拉远揭示结果。不要让所有面板、摄像机、文字同时大幅移动。
5. **动作密度有对比。** 建议 0–3 秒识别与蓄势，3–8 秒第一次持续展开，8–13 秒沿主体结构推进，13–17 秒收束变形，17–20 秒清晰落版。落版至少留出 1.5–2 秒可读时间。
6. **验证真正的连续性。** 相邻关键时刻检查同一个主物体是否仍能被指出；在转场中间帧检查是否存在合理形状，而不是画面全空、全糊或两幅图半透明叠加。

## 使用与结论边界

下载只用于内部分析；缓存位于已有 `.gitignore` 排除的 `.cache/` 中。第三方视频和抽帧不加入项目公开资产，不用于最终成片。不推断公开访问等于获得再发布许可。

本次样本为同一专业工作室的两个官方产品案例，且观看的是短片段。它们能支持“主体连续、动作先后、稳定锚点、形状匹配”的具体观察，**不能证明本项目达到行业最佳水平，也不能代表所有专业产品动效的共同标准**。成片仍需用全长播放、中间帧、文字可读性与导出结果验证。
