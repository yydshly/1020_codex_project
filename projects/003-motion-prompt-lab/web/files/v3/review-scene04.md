## 按严重性列出问题

1. **P1 / 可修 / 全局450.665帧（约7.511秒）：真峰值超限。** ffmpeg loudnorm 的 input_tp = −0.89 dBTP；独立192kHz过采样峰值为−0.891656 dBFS，位置为局部0.011078秒。原文上限−1 dBTP，超出0.108344 dB。没有到0 dBFS，不能称作削波，但硬性上限不通过。请给AAC编码后的成片留峰值余量，并复测完整导出；不要只测编码前PCM。
2. **P2 / 可修 / 全局450–461、588–599：交接主要表现为整卡淡入淡出。** 加密图中，452帧几乎只剩孤立小图标，456帧整张界面发灰；592–596帧标题、卡片、滑块和波形一起淡下去，599帧只余小图标。内容本身没有可辨认地展开成或收拢到载体，观感更像通用透明度转场；这与原文要求“转场由内容本身完成”以及 timing.json 写明“不做 whole-page opacity fade”的描述不一致。建议让波形或控件连续变为交接形状，并使前后场主体的像素位置可追踪。相邻镜头未纳入范围，因此450、600边界精确对位仍是UNVERIFIED，不能据此断言发生跳切。
3. **P3 / 可修的导演建议 / 全局510–581：版式与运动层次较朴素。** 上方和卡片右下方重复出现“教学示意”；都真实且清楚，但第二处占据视觉位置而未增加信息。波形振幅达到目标后仍连续流动，因而不是冻结；不过平视整卡的主次层级和材质精度与参考的局部构图、空间递进相比，仍显得像演示页录屏。建议保留一处明确标注，增加一次有目的的控件/波形局部构图；这是审美判断，不伪装成数值失败。
