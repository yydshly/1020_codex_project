# 风格手册

## 视觉

以真实研究集的暖白、深绿、编辑式排版为起点。片中 UI 为真实字段的重构，不是精确网站复制。

核心六色：暖白 #f3f2e9、深墨绿 #19362f、次级灰绿 #52635c、橙 #e79b40、薄荷 #c0d6ba、深背景 #102c25。
白色与细线灰为中性辅助色；因此若把所有中性辅助色也计入，超过原帖“不超过六色”的字面要求，本次不声称严格满足。

中文：Noto Sans CJK SC Regular，缓存的 OTF 文件与 SHA-256 见 font-provenance.json。标题依靠字号和留白形成层次，不伪造未注册的粗体。

## 动态

60 fps。进入缓动为 cubic ease-out；出现时间错开；片头研究卡片有小幅姿态变化。
每四秒一个场景，橙色卡片边缘在节拍边界擦过画面。
最终地址稳定呈现。这个选择优先可读性，未满足原帖的极高镜头密度与复杂转场要求。

## 音频

120 BPM。原创合成和弦、低鼓、拨弦与短操作提示音。无旁白，无品牌/艺术家模仿。
混音目标 -14 LUFS、真峰值 ≤ -1 dBTP；实际最终 MP4 数值见 verification.json。

## 使用范围

本片是 2D 产品信息演示，不包含摄影、角色动画、3D 或高复杂度模拟。
预览网页使用系统字体；最终视频固定上述下载字体，不受观看设备字体影响。
