# 实验 brief · 2026-10-20

- 类型：product，20 秒，1280×720，60 fps，仅横屏。
- 真实主题：本仓库「GitHub 项目研究集」。目标观众为收藏了很多开源工具、希望进一步理解与试用的开发者。
- 结束状态：知道研究集提供什么，愿意打开研究说明。
- 事实源：本地 README、001 与 002 的 project.json / README。002 含本地未发布内容，影片不声称这些功能已在线发布。
- 品牌：沿用研究集名称、暖白底、深色文字与绿色基调。原项目没有独立 logo，使用纯文字名称；橙色仅用于本次演示强调。
- 声音：自编电子节拍＋操作音效，无人声。由确定性代码合成，避免虚构已调用音乐模型或专业配音。
- 自主度：unattended。
- 工具链：Canvas 2D、固定版本 @napi-rs/canvas、帧函数、FFmpeg。与原帖默认工具不同，为明确记录的实现选择。
- 落版：项目名称、真实 GitHub 仓库地址。
- 设计选择：UI 为真实字段的动态重构，布局做了影片适配；不是网站录屏，不暗示按钮已在视频中真正调用产品。
- 事实与文案分离：产品功能有来源；“收藏之后，理解开始”等为原创传播文案，不伪装成研究结果。
- 参考范围：现有研究集视觉与原提示词的工艺原则。未完成行业最佳作品逐帧对标，因此不能宣称满足其最高审美标准。

## 三个方向

1. 收藏卡片转成研究档案：用一张卡片贯穿全片，具体、可与产品对应。选用。
2. 浏览器窗口穿梭：容易变成界面堆叠，放弃。
3. 抽象知识网络：画面丰富但产品信息偏少，放弃。

原设想的三个标志性瞬间：收藏卡片里的星星变成编号；编号展开成真实项目档案；档案的来源、说明、演示合为研究集入口。

**最终成片与设想的差距（独立审片后记录）**：上述连续变形没有实现。实片以重复的橙色遮罩切换收藏卡片、目录、流程与文件证据，只有语义上的串联。它没有达到这三个创意设想，不能用“完成了分镜”来代替画面的实际效果。

## 明确调整

1. 不强制“版式永远不重复”：保留卡片语言帮助认知。
2. 不强制永远运动：正文和最终网址必须能读完。
3. 音效高于/低于音乐的原文矛盾：本片选择音乐为底，短音效清晰但不遮蔽主节奏。
4. 未制作角色、对白、3D、竖屏，因此它们不属于已验证能力。
5. 全片一次独立审片，发现问题后修正；不虚称每个阶段都有新代理评审。
