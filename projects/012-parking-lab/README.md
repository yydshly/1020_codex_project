## 我们的理解与当前成果

入库之间是一款面向 C1 科二、科三的 3D 驾驶教学原型，以“看懂示范、自己判断、亲手操作、复盘重练”为学习主线。我们从可控的倒库场景出发，逐步补齐驾驶舱、实体后视镜、观察与纠偏，再扩展到科二五项、科三 17 章的完整教学串联。先用全景讲清路线、动作顺序和完成要求，再回到驾驶位，通过前方、内外镜与肩后盲区辨认车身、库线和道路变化；191 段真实 MiniMax 配合分步示范、自动观察与操作提示。学员可以暂停、手动看镜、接手驾驶，对照目标与风险反馈复盘，再从保存位置重练。

我们希望新手理解“看到什么、为什么这样操作”，逐步具备自行判断的能力。探索中的关键转变是：从全景看懂转向驾驶位辨认；把前轮回中、车身朝向和整体偏边分开；让语音、镜头与动作按阶段协调；用整车几何、有效观察时机及完整过程判定；让复盘明确首错、改法和回退点。原有倒库新手引导、语音示范、语音跟练与复盘、看镜判断回正、镜面辨认与纠偏五个专项均保留。

- **驾驶位为主，俯视为辅**：全景用于认路线和复盘，操作判断回到当前眼位与镜中可见参照。
- **讲解、镜头、动作一致**：说明看哪里、看见什么变化、何时操作，给新手足够观察时间；手动观察优先。
- **依据几何和过程判断**：核对整车位置、前轮方向和观察时机，不把到点或事后补看当作完整动作。
- **复盘服务下一次操作**：错误说明对应保存的重练位置，给出能执行的改法；回看与示范返回保留原练习。

## 遗留与后续方向

优先补齐整科实时语音带练、看镜后的风险判断、错误时刻的镜面与操作因果对照，以及 22 章正常 / 错误 / 重练全路径人工验收。后续再完善指定车型的眼位与镜面标定、完整 C1 离合与换挡仿真、练习记录保存和刷新续练、移动端及弱设备体验。车型、城市考线、随机交通和理论学习属于远期扩展。进展网页逐项列出现状、下一步、完成条件、依赖及对应已有入口。

当前仍是工程教学原型：挡位与离合自动配合，没有完整发动机、熄火、后溜或脚感仿真；镜面与车辆未按指定教练车实测标定。22 章是教学串联，非当地考线或官方评分。观察视角访问不代表已经看懂危险；练习记录主要在页面内存，刷新会丢失。492 项模型测试、191 段音频校验和代表性人工流程已验证，不能据此宣称全部章节完成了人工或实车验收。

## 为什么研究

练习者需要把驾驶位里看到的局部信息，与整个车辆的运动对应起来。这个原型让人自己尝试，随时暂停切换视角，回看刚才为什么偏了，再从那个位置重新操作。

练习闭环：**认清车身与实际可见的库线身份 → 判断车尾逼线趋势 → 小幅操作并观察同侧变化 → 主动回正 → 对照同镜前后变化或分项复盘 → 从操作前重练**。完整流程另包含两侧倒库与返回起点，指导按控制线、考试路线和观察顺序展开。

## 第一次使用：先定位，再进入六步引导

首页只呈现三步学习路径和一个主要入口。点击“从这里开始”进入右倒库分解教学；已会基础的用户可以点“我已会基础，直接跟练”。“其他练习方式”折叠保留自己练习、12 步分步示范、车内训练和完整语音示范；点击页头首页可返回欢迎页。

1. **先认车和库的位置**：用俯视图找到白色车辆和黄色标线围出的目标车库，确认相对位置。车辆保持停住，此时不需要按驾驶键。
2. **认右镜**：坐进驾驶位，通过教学放大的右镜认出细窄车身与大片地面，并回答辨认题。答错给出反馈，答对才解锁下一步；需要的参照不可见时先调镜。标签按实际投影和遮挡显示，起点库线尚未进入镜域时不要求寻找。
3. **D 向右打方向**：先听讲解、看慢放，再回到本步起点亲手按住 D；方向到位后自动停住。库线未出现时先等待，不要求提前比较不存在的参照。
4. **S 观察保持**：松开 D 后方向仍然保持；先看示范，再只按住 S 倒车。库侧线进入镜域后，辨认它与本车侧缘，观察同侧关系的变化，到观察点自动停住。
5. **交替确认两镜**：回答应比较哪组参照，再看另一侧；看同侧车身与库侧线的变化，再核对另一侧；给回轮过程留出余量，不把镜框、库口外沿、库底横线或方向盘回中当作入库方向，也不直接比较两镜像素宽窄。
6. **X 主动回正**：看过慢放后按一下 X，前轮回到正中后自动停住；完成后点击“下一步：自己判断回正”，进入下面的短练。

新手页面保留当前指令、一个主要操作按钮和场景；明确区分“停住观察”“系统示范”“轮到你操作”，并随阶段调整滚动位置。可重看当前步骤，或点“看车和库的位置”返回定位说明。教学放大不改变物理镜域，车身 / 地面标签不替代真实轮廓；本轮调整依据见 [可理解性审查](notes/clarity-audit/report.md)。D / X 小步骤由系统代管低速倒车，速度上限为 1.8 km/h；S 小步骤由用户控制倒车，松手即教学暂停。分解教学会自动停住；完整练习由用户自己控制车速。

## 镜面辨认与小幅纠偏

工具栏的“镜面辨认与纠偏”提供左右对称、车尾带小夹角斜入的场景。先分清镜中本车侧缘与沿库位长度延伸的库侧线。起点 L 形黄线的大横段是库口两侧的外沿，不是远处库底线；库口中间保持开放。库尾横向封口才是库底线，只有实际可见时才标注。两镜车身可见、侧线有足够连续可见段时，才要求判断继续直倒的逼线趋势；孤立黄线点、库口外沿或库底线都不能代替库侧线。需要重新认镜时，可返回镜面辨认。

1. **看镜并判断车尾走势**：观察同一面镜里车身与库侧线的近远间隙和走势，再核对另一侧。镜中侧线可能倾斜或弯曲；先确认横向黄线属于库口外沿还是可见库底，不要把两镜像素宽窄直接当成实际余量。教学放大开启时切换左 / 右镜会保留放大。库线尚未进入镜域时，不要求寻找隐藏的后轮或库角。
2. **亲手开始小幅转向**：听完真实 MiniMax 提示后，由自己按 A / D 控制方向盘。这两题分别为车尾向左 / 右斜入，向另一侧小幅转方向盘，使车尾轨迹逐渐改变；车头会向相反方向外摆，仍需观察前方和另一侧。车辆不会瞬间横移，也不能将本题答案泛化为所有“左侧紧就右打”。系统辅助 1.5 km/h 低速并把目标转角限制为 8°；松键保持转角，空格制动，P 教学暂停。
3. **观察点停住，再主动回正**：预测直倒余量改善至本模型的 8 cm 教学门槛后自动暂停。确认镜中变化，再按 X 主动回正；只有实际前轮回到零度并具备直倒余量，才判本次纠偏改善。错误方向、过早回正、保持过久、超时或触线会停练并说明原因。
4. **同一面镜前后对比**：结果展示操作前与本次回正后的同侧镜面，使用同一组座椅和镜面设置。可从操作前重练，并保留当前看镜方向、转头角度和教学放大状态。

该专项只练带小夹角斜入的观察、小幅转向与回正。车身已经平行但整体偏边需要另一种调整过程，不能直接套用本题单次修正；辅助控速和关键点暂停也不等于完整驾驶操作。具体审查、外部原则与工程边界见 [本轮后视镜检查](notes/mirror-coaching-20261024/audit.md)；原学习闭环的历史版本证据见 [前轮验证](notes/learning-loop-20261024/verification.md)。

## 看镜判断回正：示范、判断、对比、重练

从首页“看镜判断回正”、工具栏短练入口或新手课程末尾进入，可选择右倒库或左倒库。完整带练的回正复盘卡片也提供“看镜重练回正时机”入口。

顶部四步进度明确标出 **看示范 → 自己判断 → 对照镜面 → 重练**，当前步骤高亮。独立讲解状态显示准备、播放或失败信息，不与车辆速度、暂停状态混写；结果页继续以“从出错前重练”为主要操作。

1. **看一段示范**：观察车身与库线从倾斜到趋近平行，示范演到前轮归零就停住，与本次短练的终点一致。
2. **自己判断**：按住 S 低速倒车，交替看两镜，自行决定何时按 X。页面只保留倒车、回正、暂停三个常用操作，练习中不提前播报“现在回正”。系统限制低速，用户决定操作时机，P 可教学暂停。
3. **对照镜面**：回正完成或明显错过时机后自动停住，展示本次与示范的左右镜面。图像由记录姿态重新渲染，使用同一组座椅和镜面设置；青色只描出实际可见车身侧面的参照段，金色标出同侧库侧线，遮挡处不画，不再用地面方向投影冒充车身边缘。
4. **从操作前重练**：回到本次问题前的已有姿态，以零速准备，清除旧的回正输入及后续操作；也可重练整段、换侧或进入完整语音带练。

镜面对比配对的是双方各自开始回正的动作时刻，便于比较“我看见什么时做了操作”；没有按相同秒数拼图。若没有按 X 就错过时机，会明确说明尚未回正，展示错过时的记录。原有轨迹复盘继续按行驶距离配对，两种对照用途不同。

接手、重练和短练阶段切换会保留已有的看镜方向、手动转头角度与教学放大状态，减少操作前重新找镜。新进入训练且尚未选镜时，再采用对应侧的观察方向。眼位改变后重新按当前座椅计算镜心。

时机反馈结合回正过程及之后直倒的整车路径检查，车身夹角小也可能因边线余量不足而需要重练。“时机合适”表示本模型预测继续直倒可以入库，不代表已经完成实车入库或考试合格；仍需继续观察和判断停车位置。本短练及辅助判断尚未经过实车验证。

## 语音示范与带练

展开“其他练习方式”后选择“语音示范与带练”，默认从驾驶位观察两侧镜面。点击“开始完整示范”，按 21 段依次演示 **A 端准备 → 右倒库 → 出库至 B → 左倒库 → 返回 A**。转向与回正前单独提醒观察和准备，操作后提示保持方向；每段先保持车身不动、播放讲解与同步字幕，再演示对应动作。讲解中的教学暂停不计入车辆练习时间。

- **暂停与重听**：P 或播放按钮同时暂停车辆和当前语音，继续时从原音频位置恢复；“重听讲解”先暂停动作。支持上一段、下一段、完整时间轴、音量、语速与关闭语音只看字幕。
- **常用操作优先**：开始 / 暂停、接手和复盘入口保留在主区域；其他示范步骤、重听、音量、语速及完整字幕收进“更多示范与设置”。旧侧栏与重复提示收起，让镜面及速度、转角、刹车、暂停更容易找到。
- **先看哪里，再做什么**：“看哪里 / 现在做 / 接下来”三栏与镜面高亮同步。右倒库先看右镜、左倒库先看左镜，接近回正时交替观察两侧；提前准备与立即操作分别显示，避免把“准备回正”误当成“现在回正”。
- **从这里跟练**：保留示范当前车身位置及转角，先以零速进入教学准备，不计时，直接讲解当前姿态需要的操作。可先按 Q / E 看镜，再用 S / W / X 或“开始这段练习”启动；也可以从 A 端开始完整路线。
- **跟随真实操作**：准备转向、到参照打方向、保持转角、准备回正、主动回正和停车等提示由当前车身位置和路线进度触发。预告时机结合设定车速与讲解语速调整，转向 / 回正准备使用独立短句；立即操作口令精简为“右打方向”“左打方向”“回正”“刹车”，实测分别为 1.224、1.260、0.936、0.936 秒。关键操作与出线提醒可打断旧讲解，不会把过期提示排队播放。
- **前轮回正后仍检查车身**：普通指导与语音指导使用同一套运动判断。若前轮已正但车身仍斜，或继续直倒将缺少边线余量，会提示先刹车、暂停观察并重练，不再把这种状态当成可以直接直倒或重新打满方向。
- **同一位置反复练**：“重练接手位置”恢复本次接手时的车身、转角和路线进度，重新静止准备；“再看这段示范”返回对应示范段，可看过后再次接手。
- **暂停复盘后继续**：暂停时语音同步暂停；拖回历史姿态时，标题、字幕、三栏和镜面推荐立即跟随所选位置，恢复练习后再按该姿态播报。打开指南或调镜也会暂停语音，包括已经静止的接手准备阶段。
- **车内与复盘**：驾驶位、俯视、跟车、后视镜放大和座椅调节都可用。真实考试仍需按车型、座椅及教练校准点位；原型语音用于练习观察和操作关系。

新的默认语音来源为 MiniMax 预生成 MP3：真实生成使用 `speech-2.8-hd`、`male-qn-qingse`、语速 `0.95`，音频为 32,000 Hz 单声道。浏览器播放本地语音包，不在练车过程中直接调用生成 API。`src/narration.js` 包含 48 段文稿，涵盖认镜、短练开场、自主判断、漏回正和小幅纠偏。活动清单对应 48 段音频，保留的旧版本 MP3 不计入活动包数量和体积。详见 [本轮生成与校验记录](notes/audio-correction-2026-10-24/generation.md)。

所有模式都能看到语音包状态。缺包、文稿不匹配或讲解播放失败时，语音教学会停在当前步骤，重试不会被当成讲解成功；用户点击“先用字幕练习”后才按字幕继续，也可主动“启用 MiniMax 语音”。旧 39 段 Huihui WAV（16,309,564 字节，约 16.31 MB）仍保留在 `public/audio/`，不作为新的默认音源或隐式后备。

## 跟练复盘：看清时机，从出错前再练

在语音带练中点击“暂停并复盘”，车辆与语音停止，按本次记录分别分析右倒库和左倒库。有行驶或明确转角变化的记录即可打开复盘，包括停住后原地回正；完全静止且没有操作变化时不开放空复盘。出库中的转向不计为倒库动作。

- **打方向与回正独立反馈**：分别显示偏早、偏晚、接近模型参照或尚未记录。回方向进行中先保留为待完成，实际前轮回到零度后，用记录中的完成姿态及实际回轮过程检查直倒路径；卡片跳转仍定位开始回正的一刻。
- **区分时机与过程**：记录 `reviewInput` 中的倒车、前进、制动、回正和速度设定。原地回正、回轮中刹车或改速会按实际车身变化解释，不再假设持续倒车重演一次；旧记录缺少输入字段时仍依据实际姿态和车速，不虚构操作原因。回正过程中出线单独提示，正常连续回轮的早晚反馈保留。
- **缺失过程如实保留**：中途接手时，如果此前打方向或回正起点没有录到，显示未记录，避免把接手前的动作算作自己的操作。
- **两条轨迹直接对照**：小地图以真实场地坐标显示库位、本次青色后轴轨迹与完整金色虚线示范，保留横向偏差和路线差异。示范车轮廓先按接手初始空间姿态定位，再按累计行驶距离对照；不按时间同步，不平移或旋转轨迹去贴合。
- **回到操作那一刻**：点击打方向或回正卡片、拖动时间轴，可查看对应车身轮廓；“驾驶位看当前点”回到该姿态观察左右镜，再返回轨迹对比。
- **看镜重练回正**：回正卡片中的新入口进入对应侧的短练，先观察示范，再自己判断和对照镜面；原“看回正这一刻”按钮继续保留。
- **从出错前重练**：选取首个问题发生前约 1.8 秒的已有记录，以零速进入准备；不足时退到本段最早记录，并说明原因。保留重练点之前的轨迹与已完成操作，用新操作替换之后的记录；没有明确问题时可以重练本段，也可从当前回看点继续。

早晚反馈采用本模型的位置、转角、速度和回方向过程，仅用于理解观察与操作关系，不是实考评分或各车型通用的点位。轨迹与复盘只保存在当前页面内存中。

## 原有分步示范

在“其他练习方式”中点击“分步示范”，默认在关键点自动暂停。每步说明“怎么做、此时看哪里、要避开什么”。支持上一步、下一步、任选步骤、0.5× / 1× / 2× 播放，以及关闭关键点暂停后连贯播放。示范暂停时可切换驾驶位、俯视和跟车，拖动整段时间轴查看任意姿态。

1. A 控制线外准备；两个前轮已越线。
2. 低速直倒，找本车型转向参照。
3. 向右打方向，先认右镜车身与侧后地面，库线入镜后比较间隙，并兼顾外侧车头。
4. 车身趋于平行，准备回方向。
5. 主动回正到前轮 0°，继续直倒。
6. 同时确认车头、车尾在线内，刹车停稳。
7. 先直出再向左，前往 B 控制线。
8. 两前轮都越 B 线，停稳换倒挡。
9. 左倒库，按镜像观察顺序转向和主动回正。
10. 库内停稳。
11. 先直出再向右，返回 A 端。
12. 示范结束，复看或切回自己练习。

“从这里接手练习”保留示范当前车身位置与转角，以零速交还控制；“自己练习”从 A 端重新开始。示范中的模型转向参照不是所有真实考试车通用的点位。

原有分步示范也使用共用观察提示：结合当前镜域和实际遮挡说明先找车身、是否需要调镜，以及库线何时可供比较；不会因旧步骤文案要求寻找当前不可见的后轮或库角。按钮聚焦后保留原生 Space / Enter 激活，驾驶快捷键不再吞掉按钮的空格操作。

## 新增：车内观察与后视镜训练

在“其他练习方式”中选择“车内训练”，默认坐在驾驶位并隐藏轨迹和模型转向参照；仍可暂停切俯视对照，也可自行打开辅助。自己练习、分步示范、跟车和时间轴继续可用。

- **常态观察与教学放大**：常态只显示车上的实体镜片。Q / E 或看镜按钮将视线转向对应镜心，包含实际高低角度，C 回到正前；“教学放大”按钮或点击实体镜片才打开辅助浮层，新手教学也可显式放大。实体镜片和浮层共用源纹理与反射 UV，放大不改变孔径、射线或镜中视域。拖动车内画面仍可转头，驾驶键保持可用。
- **驾驶位比例**：车内外共用窗口与立柱，眼位、镜片和镜壳保持统一空间关系。驾驶相机横向 FOV 上限为 100°，避免短而宽的画布把车舱拉成超广角；这只是屏幕显示约束，不是眼位标定，也不改变后视镜光学视域。完整语音带练场景最小高度为 420px，并保留场景内暂停按钮。
- **先调座椅再调镜**：驾驶位下方可打开“调座椅”，调整高低和前后；眼位改变会实际改变镜中画面，只提示重新推荐，不偷偷修改镜角。每面镜仍可独立微调。调节时教学暂停，完成后由用户继续；顶部“镜面参考”可展开简短说明。
- **一键推荐与撤销**：场景和工具栏的“帮我调好后视镜”按当前眼位推荐两侧镜；单侧调镜面板只调整对应一侧，座椅面板和完整设置可推荐双侧。默认眼位下推荐左 10° / −19.8°、右 8.3° / −19.1°。应用前暂停，不自动继续；“撤销这次调镜”恢复本次之前的镜角而不移动座椅。推荐只依据固定车身边和近远地面，不读取车库或当前行驶姿态。
- **镜中认物**：普通模式的“镜内辨认辅助”和原车内设置中的开关同步，默认关闭。后轮 / 库角标签使用与画面相同的球面投影，并检查不透明场景物体遮挡；目标不在实际镜域内或被挡住时不显示。新手另有车身 / 地面教学标记，同样按实际投影和遮挡显示；起点先认车身与侧后地面，倒车时等库线进入镜域，不强求完整轮胎可见，也不以标签代替实际轮廓判断。
- **交替观察**：右倒库以右镜为主、左倒库以左镜为主；车身接近顺直时提示交替检查两侧夹角与余量，出库时提示看正前和侧窗。
- **专项起点**：从起点练、库角观察、回正观察、车内看示范。专项起点以零速载入对应车身与方向角，方便马上练这一步；俯视仍可用于对照。
- **看镜回正专项**：车内入口上方可分别选择右倒库、左倒库。从已有连续示范中提取接近顺直的姿态，零速载入，先教学暂停观察。开始后按住 S 倒车，看准时机按 X 主动回正；完成回正或出现明显偏差后自动教学暂停，解释偏早、偏晚或接近顺直，并显示本次结束时的车身夹角、前轮转角和开始回方向时的夹角。练习途中不显示这些数值提示时机。
- **对照与重练**：专项俯视聚焦库口，能看车身、两侧间隙和刚才的轨迹；可返回驾驶位、再练同一侧或直接换边。专项属于局部练习，不计算完整考试路线结果，反馈阈值也不是实考评分标准；完成回正后仍需继续直倒、按停车参照停稳。
- **固定观察条件**：新光学模型使用独立的 `parking-lab.cockpit.v2` 保存座椅和两侧镜面设置，刷新自动恢复；旧版设置不删除，也不直接套用到新模型。“恢复初始座椅与镜面”只更新当前版本设置。浏览器禁用存储时仍可在当前页面调节。调镜后按 P 会关闭面板并继续练习。

当前仍是屏幕原型。镜面按有限球面逐点求反射射线，并用同一光学变换生成实时镜面和复盘截图；场景颜色来自最小二乘拟合的虚拟视点，仍有近场视差近似，默认最大采样射线原点误差左约 13.48 mm、右约 20.36 mm。这不是实车校准精度，也不是整幅图像误差。尚未模拟双眼视差、方向盘力反馈或实车离合脚感，眼位与镜片参数均为工程参考，不能直接当作具体考试车的点位。详见 [参数与近似边界](notes/mirror-calibration.md)；[旧镜面审查](notes/mirror-audit-2026-10-24/report.md)作为修复前证据保留。

## 快速运行

需要 Node.js 22.12+（已在 22.15.0 验证）。在本子项目目录执行：

```powershell
cd F:\codex_project\1020_codex_project\projects\012-parking-lab
npm install
npm run dev
```

打开 [本地练习场](http://127.0.0.1:4312/)。服务只监听本机地址。

构建后也可以执行 `npm run preview`，或者运行 `powershell -NoProfile -File .\start.ps1`。启动脚本会复用已运行的本项目服务；没有服务时在后台启动构建产物，并打开浏览器。后台日志与进程 ID 保存在被忽略的 `.local/`。网页运行无需 API 密钥或登录，构建产物不依赖外部 CDN；生成 MiniMax 语音包需要单独配置凭据。

### 重新生成或验证 MiniMax 语音包

当前语音包已生成，无需重新配置即可练习。修改文稿或在其他环境重新生成时，使用项目外包含 `MINIMAX_API_KEY` 的私有 `.env` 文件，或通过当前进程环境提供。可选配置为 `MINIMAX_BASE_URL`（兼容 `MINIMAX_API_BASE`）、`MINIMAX_MODEL`、`MINIMAX_VOICE_ID`；脚本只接受官方 HTTPS 接口。下方占位路径需替换为已有文件的绝对路径，不要将密钥写进网页、命令参数或项目文件。

首次使用新的配置时，可先只生成一段，以真实请求确认账号、模型和音色可用：

```powershell
npm run speech:generate -- --env-file "<项目外绝对.env路径>" --key judgment_intro --limit 1
```

这里 `--key judgment_intro` 选择文稿编号，不是 API 密钥；单段成功也不代表完整语音包已就绪。确认后再全量生成并校验：

```powershell
npm run speech:generate -- --env-file "<项目外绝对.env路径>"
npm run speech:verify
npm run build
```

输出位于 `public/audio/minimax/`，包含 MP3 和 `manifest.json`；清单记录模型、音色、文稿、时长、字节数与 SHA-256。重复执行会复用配置、文稿与文件哈希一致的音频，缓存命中不再请求 API；实际请求默认至少间隔 6,500 毫秒，失败不会自动重试。`speech:verify` 检查全量文稿和全部文件哈希，当前 70 段完整包已通过。

API 密钥仅由 Node 生成脚本在内存读取并用于请求鉴权，不写入公开清单、音频或前端构建产物。完整包通过校验后，页面加载清单，并在驾驶前预缓存关键操作提示；生成失败不会用旧 WAV 冒充 MiniMax 结果。

车辆从 A 控制线外开始。按 C1 观察与方向专项训练：低速设定简化半联动控速；到转向参照再打方向；车身趋近平行时主动按 X 回正；车身完全入库后刹车停稳。两侧入库都要做，并前进返回起始端。界面会随姿态改变“直倒、打方向、主动回正、刹车”的提示，提醒控制线和路线顺序。

场地依据 GA 1029—2022 小型载客汽车参数：库宽 2.3 m，库长为车长加 0.7 m（本车型为 5.1 m），车道宽及库边至控制线距离均为 6.7 m。计时显示 210 秒参考时限；教学暂停冻结计时，明确不代表实考可以这样停车。没有模拟离合脚感、换挡联锁或熄火，也不输出完整考试分数。库内“停稳”几何阈值为本原型的判断值，并非标准规定的角度和速度阈值。

绿色是后轮轨迹，橙色是前轮轨迹，灰绿色虚线是当前转角下约 3.8 米的预计路线。暂停时显示历史车身轮廓；拖动时间轴查看对应时刻的车身、速度和转角。从历史位置继续会以零速起步，并重新记录之后的轨迹。

## 原理与结构

- `src/full-courses.js` / `courses.html`：科二科三分段示范、基础驾驶、风险反馈、观察记录和练后复盘的页面流程；既有 MiniMax 示范讲解与倒库专项保留。
- `src/course-practice.js` / `src/course-practice.test.js`：22 章基础练习目标、到访观察视角、完成条件、错误记录、缺项复盘、示范轨迹比较及错误前重练状态。
- `src/course-practice-ui.js` / `src/course-practice.css`：目标清单、下一步观察按钮、风险原因、等比例轨迹图与复盘重练入口；静止练习不展示空行驶轨迹。
- `src/course-safety.js` / `src/course-safety.test.js`：实际道路矩形／曲线路面、全车道路与库线检查、轮胎实线接地区、场景权威碰撞体、相对运动扫掠以及风险前安全位置；提醒不等同实考评分。
- `src/course-observation.js` / `src/course-observation.test.js`：同一驾驶眼位下的前方、两侧外镜、车内镜和左右后方转头角度，区分看镜与肩后观察。
- `src/course-interior-mirror.js` / `src/course-interior-mirror.test.js`：实体车内平面镜、真实镜面反射投影、眼位调整和源渲染状态恢复，不使用车尾摄像头替代内镜。
- `src/course-scene.js`：各章道路、车、人及灯光场景，按实际物体姿态提供安全检测上下文；路口开口、沥青前庭与标线保持一致。
- `src/main.js`：Three.js 场景、车辆几何、三种视角、后方观察窗、键盘与指针控制、轨迹缓冲区和内存回放。
- `src/beginner.js` / `src/beginner.test.js`：六步新手引导的局部起点、单动作输入、辅助低速、完成条件与模型验证。
- `src/beginner.css`：首页三步学习路径、折叠的其他模式、新手单指令界面及当前镜面强调。
- `src/judgment.js` / `src/judgment.test.js`：左右回正时机短练、同速度参考路线、实际决策记录、几何反馈及保留前缀的重练。
- `src/observation-guide.js` / `src/observation-guide.test.js`：各模式共用的真实可见性提示和认镜题，参照不可见时先调镜，辨认错误时说明依据。
- `src/correction.js` / `src/correction.test.js`：左右对称小偏差、1.5 km/h / 8° 辅助、小幅纠偏及实际回正结果，覆盖错方向、早回正、过度保持、制动和边线。
- `src/learning-loop.css`：认镜题、小幅纠偏控制和同镜前后对比布局。
- `src/judgment.css`：短练的简化控制与真实镜面对比，以及完整语音带练的紧凑布局与折叠设置。
- `src/audio-flow.css`：全模式语音包状态、显式字幕选择、短练四步进度及独立讲解状态。
- `src/steering-coach.js` / `src/steering-coach.test.js`：普通与语音指导共用的回正窗口、回正过程与后续直倒路径预测、车身偏斜和边线余量纠偏。
- `src/vehicle.js`：独立的低速自行车模型，状态锚点为后轴中点；轴距 2.65 m，车长 4.4 m、车宽 1.8 m，最大前轮转角 34°。速度、轴距和转角共同决定车身偏航；变速时先制动再反向。
- `src/car-body.js` / `src/car-body.test.js`：带轮拱的车身几何，配合 1.52 m 轮距和 0.23 m 胎宽，使后轮及回正前轮的轮胎、轮毂外缘留在车身范围内，前轮转向保留正常扫掠。
- `src/driving-yard.js` / `src/driving-yard.test.js`：米制灰路面、贴地漆线、驾驶范围外设施与独立教学辅助，验证场地边界和纹理复用。
- `src/scene-geometry.js`：路面、漆线、地面参照和教学层共用高度，避免标线或观察点使用不一致的几何表面。
- `src/driver-view.js` / `src/driver-view.test.js`：按镜心与眼点计算水平 / 垂直观察角，并限制驾驶位横向 FOV。
- `src/lesson.js`：12 步文案、同一车辆模型生成的连续示范、两侧镜像与倒放出库、路线阶段跟踪、实时驾驶指导。
- `src/cockpit.js`：驾驶员眼位、有限球面与固定参考眼点调镜、镜面射线和目标逆投影、v2 观察设置与路线提示。
- `src/mirror-optics.js` / `src/mirror-optics.test.js`：最小二乘虚拟视点、球面射线 UV、实际镜域及源纹理相机范围、近场近似误差验证。
- `src/mirror-surface.js` / `src/mirror-surface.test.js`：车辆实体镜片的局部几何与反射纹理 UV，与教学浮层使用同一光学来源。
- `src/mirror-fit.js` / `src/mirror-fit.test.js`：按当前眼位和固定车身 / 地面参照独立推荐两镜，0.1° 输出，报告受限结果，不读取车库或车辆姿态。
- `src/mirrors.js` / `src/mirrors.test.js`：实时与复盘共用的球面映射、独立渲染目标、标签不透明遮挡检查、镜面快照及渲染状态恢复。
- `src/mirror-training.css` / `src/realistic-scene.css`：实体镜常态与教学浮层的显隐、镜面辅助、场景内控制及紧凑窗口布局。

- `src/review.js`：按左右入库阶段分析已记录的打方向与回正起点，依据实际完成姿态及输入记录区分时机、刹车和变速过程，保留缺失过程、车身出线及出错前重练位置。

- `src/review.test.js` / `src/review-map.test.js`：操作早晚与缺失记录、重录后替换未来、不同速度及反应延迟、距离配对、半程接手、空轨迹与可访问说明。
- `src/narration.test.js` / `src/voice-guide.test.js`：音频取消和暂停竞态、音源解析、整段轨迹覆盖、左右实时提示与警告优先级。

## 结论与后续

- 已具备“认镜—判断紧侧—小幅操作—主动回正—同镜前后对照—重练”的专项学习闭环，并保留示范、接手、分项复盘及完整双侧路线。
- 场地按标准参数构建，车型为工程参考几何，采用低速运动模型。考试区域提供车身出线提示，外围边界阻止驶出；围墙、车棚等设施布置在驾驶范围外，未额外模拟装饰物碰撞。后视镜采用有限球面反射与眼位关系，场景取色仍有虚拟视点近似，尚未经过实车校准。
- 轨迹只保存在当前页面内存中，刷新即清空；采样到容量上限（约十分钟）自动暂停。支持触屏按钮；本轮在默认用户窗格观察，未做手机真机或断点专项验收。
- 下一轮需根据实际考试车型、城市和用户座椅位置校准视角与点位，再扩展离合、挡位和更完整的评判。
- 本轮没有执行渲染性能专项优化或实车 C1 脚感标定；辅助低速和 8° 小转角仅用于本模型专项教学。
