# 操作一致性与同步示范

2026-10-24。用户授权优先修正方向盘、前轮、车速和踏板提示，再完善操作示范与同步语音，保留科二科三和原倒库功能。

## 运动与操作同源

- 非原倒库的21章用同一连续位置曲线导出车速、车身朝向、前轮角和有符号路程；稀疏关键帧使用保持停位的单调Hermite，变道使用五次平滑横移，弧线路径按路程重定时。保留章节时长、停车点和行驶走廊。
- 车速与位置导数、转角与 `yawRate = speed / wheelbase * tan(steer)` 对照检查；原倒库改直接读取原120Hz示范帧，保留原专项模型与路径。轮胎转动改从有符号路程求角度，停住后不会因播放时钟继续转轮。
- 起步、减速、停车、离合结合、换挡和驻车状态统一输出给HUD与三维部件。消除原人行横道重新起步的脚刹/离合继承，以及坡起位移与车速分别插值的问题。
- 变道/超车的平顺横移速度模变化不再被自动当成踩刹车；两章显式保持脚刹松开和轻油门。
- 集成检查发现章节加教案时的浅拷贝绕过了原WeakMap sampler；已按共享 `poses` 身份补取值并添加实际播放器装饰章节的速度、转向和路程回归。不是仅在原对象单测中通过。

## 可观察的操作与同步语音

- 新增121个短操作教案，与22章的关键时刻绑定。变道与超车各8步；侧方与靠边各8步；倒库14步；上车准备7步；灯光8步。转向、反向回轮、回中分开说明，库角尚未入镜时先认车身和地面。
- 默认在关键操作前0.35秒教学暂停，播真实MiniMax短提醒，结束后继续动作；0秒或提前编排的提示按各章时刻执行。0.5/1/2/4×动作速度不会跨过语音门控。主动关闭语音可连续看动作。
- 每步可单独选择或重看。手动重看也从提醒门控前开始，避免灯光已切好后才说“打开近光”；暂停、静音、跳章、拖动进度和旧语音迟到事件均保留取消/冻结规则。
- 原22段本项总讲解可在“讲解”中切回。原48段倒库语音继续独立验证和使用，不会要求倒库页加载全部课程提醒。
- 课程实例增加三踏板、H形挡杆、手刹、灯光拨杆/旋钮、双闪与仪表指示；准备章可观察开关门、座椅/调镜控制和系带。安全结束先解带再开门。
- “操作近景”是用户主动选择的教学辅助视角，按目标聚焦。门/安全带保留空间构图，拨杆、挡杆和踏板有独立相机；检查部件投影大小和首个遮挡射线。驾驶位眼位/FOV、物理镜域及原倒库共享模型未改。
- 修复新增灯光开关Group被旧外灯遍历误匹配的阶段启动错误，并用实际外灯识别函数做回归。近景字幕说明当前部件；观察外部环境的步骤不会误表示正在调镜。

## 追加：整科页直接驾驶

用户在本轮中进一步要求当前页可直接控制，已在同一播放器加“看示范 / 自己驾驶”，保留自动示范与旧倒库入口。

- 基础自行车控制模型固定200Hz子步；30/60/120fps结果一致，支持W/S、A/D、空格、X主动回中。松转向键保持角度；换向前先停稳；前进最大8m/s、倒车1.5m/s，并随速度限制新转角、按持有转角限速。
- 接手时保持位置、朝向、前轮角和驾驶/看镜视角，车辆先停稳置N；重置回本项起点并暂停。回示范返回接手前时间点，旧自动语音停止，手驾不显示旧轨迹口令。
- 示范速度倍率不影响手驾；P、失焦、切后台、目录打开、切章、切模式与重置会清键。鼠标/触屏按住按钮支持pointer capture和释放。基础灯光可单独切换。
- 支持 `?course=subject3&chapter=straight&mode=drive` 直接进入。坡道姿态依据实际宽度、上坡/平台/下坡计算，离开实体不会悬空。
- 范围边界按车辆完整角点检查并停止；未实现建筑/行人碰撞裁决、完整发动机/离合力学或考试评分。手驾是基础方向、控速和观察练习，不宣称真实C1全操纵仿真。
- 新增9项手驾数值回归，总检查271项通过；另由独立复核检查过控制器输入、冻结、清键与模式切换。
