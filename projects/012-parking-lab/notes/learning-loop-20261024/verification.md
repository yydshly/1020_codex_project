# 2026-10-24 学习闭环实现与验证

本轮把“认镜—判断紧侧—小幅操作—主动回正—对照变化—重练”做成独立专项，同时修正完整带练的回正复盘、保留观察方向，并统一各模式的真实可见性提示。旧报告、旧构建和旧音频记录保留；本页分开记录实现、模型测试与浏览器事实。

## 稳定实现

- **实际完成姿态复盘**：`review.js` 依据已记录的实际前轮零转角姿态预测后续直倒，检查真实回轮区间是否触线，不再从起点假设持续倒车重演回正。开始回正的 `index` 保留用于卡片跳转，另记录 `startIndex` / `completedIndex`。`reviewInput` 保存前进、倒车、刹车、回正和速度设定；缺字段旧记录仍依据实际姿态和速度，不猜测未记录的刹车或改速原因。原地回正或回轮中改速导致的过程问题与正常早、晚反馈分开说明。复盘入口通过 `canReviewPractice` 判断：记录有行驶或明确转角变化即可打开，不再要求原地 X 先满足行驶距离；无变化 idle 记录不开放。
- **保留观察状态**：接手、重练及短练阶段切换保留已有看镜方向、手动 yaw / pitch 和教学放大；眼位改变时重新按座椅与镜心计算观察方向。新进入且尚未选镜时使用当前训练侧作为观察起点。
- **共用可见性语言**：`observation-guide.js` 接收 renderer 的实际镜域和遮挡结果，先检查车身是否可见，再判断库线是否入镜。原有分步示范也使用这一套提示；隐藏的后轮或库角不作为必须找到的参照。
- **认镜门禁**：新手先辨认车身，再判断应比较车身与库线的夹角及两侧间隙。答错显示原因，答对且所需参照实际可见时才解锁下一步。
- **左右小幅纠偏**：左右对称起点带小偏差，observe / ready 阶段先检查两镜车身与库线的真实可见性，再判断紧侧；听完 MiniMax 提示后自己按 A / D 开始。系统辅助 1.5 km/h，目标转角上限 8°；松键保持转角，空格实际制动，P 教学暂停。预测直倒余量达到 8 cm 教学门槛时自动暂停，按 X 实际回到零转角后才评价。结果展示同一侧、同一镜面设置下的操作前后画面，重练保留当前观察方向。错方向、过早回正、反向摆过、长时间保持、超时或触线会停练。
- **输入与暂停**：聚焦按钮时 Space / Enter 保留原生激活；全局驾驶快捷键忽略 Ctrl / Meta / Alt 组合。纠偏中的失焦、帮助或规则弹窗会教学暂停。准备讲解可暂停、恢复，显式字幕继续进入等待本人开始的状态。

## 范围与模型边界

本轮未执行渲染性能专项优化、场景重做或实车 C1 脚感标定。1.5 km/h 辅助低速、8° 目标转角和 8 cm 教学门槛仅用于当前小幅纠偏模型；它们不是实车点位或避线保证。`steerLimit` 限制转向目标，不在无转向输入时强制压回已有大转角；专项从零转角起步，未来若复用已有大转角姿态需另行处理。手机真机与真实考试车型仍未验证。
