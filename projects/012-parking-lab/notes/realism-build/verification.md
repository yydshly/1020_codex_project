日期：2026-10-24。本记录区分稳定实现、模型测试与实际浏览器证据；过程图不自动视为最终效果。

## 本轮实现

- 场地采用灰色路面、贴地黄色库线，围墙、铁网、少量蓝色项目牌、路障、低矮建筑及车棚位于驾驶范围外。网格、库内填色和尺寸字默认关闭，保留为教学辅助。
- 路面顶 0.025 m、漆线 0.027 m、地面参照 0.028 m、教学层 0.030 m 共用高度定义。库位及控制线继续使用原 `BAY` / `COURSE` 坐标，车辆运动参数未改。
- 同一白色 C1 工程参考车共用内外窗口，加入倾斜 A 柱、门板、仪表台和独立方向盘；实体镜片附着镜壳。镜面纹理准备、主场景实体镜、可选教学浮层按顺序绘制，实体镜与放大画面共享源纹理及反射 UV。
- 常态只显示实体镜。Q / E 或看镜按钮按镜心与眼点计算水平、垂直视线；教学放大按钮或点击实体镜片打开浮层。座椅、单侧调镜、一键推荐、撤销及原示范、语音、短练、复盘继续保留。
- 驾驶相机横向 FOV 上限为 100°，避免短宽画布造成超广角；完整语音带练场景最小高度 420px，并提供场景内暂停按钮。
- 路面贴图 `assets/textures/yard-asphalt-v1.png` 为内置 imagegen 生成的底色素材，4,638,410 字节，非实地扫描；完整来源与 prompt 见 [素材记录](assets.md)。外观照片和素材不构成实车眼位、镜片或厂家标定。

## 实际流程与最终构建边界

- **完整带练，`index-oe2YU751.js`：** MiniMax 准备讲解 → S 倒车 → 场景内暂停 → 轨迹 131 点、约 0.84 m → 复盘 → 回正短练，实际操作通过。
- **短练闭环，`index-BkWCR5Tt.js`：** 右镜示范中的真实 MiniMax 讲解自然结束 → 准备好了自行判断 → S 约 1.2 秒 / X 约 1 秒 → 回正偏早 → 四张实际新镜面对比 → 从出错前重练。重练后旧输入清除，车辆等待新的 S 输入。输入时长仅记录本次测试，不是实车点位。
- **眼位与调镜：** 座椅由 1.28 / 1.10 m 调高至 1.35 m，页面提示需要重调镜；按当前眼位调好两侧镜成功。随后恢复 1.28 / 1.10 m 并重新适配，未把旧眼位的镜角视为通用标定。
- **窄窗：** 824×871 视口实际确认看镜和教学放大控制可见，证据为 `12-narrow-mirror.png`；不由此推断所有尺寸或手机真机均通过。
- **最终构建：** `index-L0xOqOMh.js` / `index-oV8a99Z0.css` 相对已验证闭环仅修改 HTML / CSS，把暂停按钮移到场景右下以避开教学镜卡标题。824×871 下已实际确认实体镜、教学放大卡、控制条和右下角继续按钮可见；完整闭环证据仍归属上述原构建，显示复查不代替重新手工执行整段流程。
- **最终继续 / 暂停：** 恢复原窗口，关闭教学放大并回到正前；实际点击继续进入“由你驾驶”，再点击暂停回到教学暂停、0 km/h。MiniMax ready，浏览器 error / warn 为空，交付页面保留暂停可体验。

最终预览为 [带练提示与驾驶舱](../../assets/preview-realistic-cockpit.png)、[实体镜与教学放大](../../assets/preview-realistic-mirrors.png)、[场地](../../assets/preview-realistic-yard.png)，三张均已实际打开查看，驾驶舱图作为 README 首图和项目封面。该封面含语音就绪与先看右镜提示，底部在场景控件处截断，不能称作完整页面截图；最终窄窗控制可见性由 `13-final-narrow-practice.png` 单独记录。既有审查图与各轮预览继续保留。
