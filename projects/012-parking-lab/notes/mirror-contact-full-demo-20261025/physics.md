# 外后视镜实体擦碰验证 · 2026-10-25

本轮为科二、科三课程场景补充外后视镜实体擦碰检测。镜壳与支架使用实际渲染几何独立检测，不通过加宽整车碰撞盒实现。原倒库车模、镜面反射、示范和语音功能保留。

## 几何与坐标

- `course-mirror-collision.js` 从 `createTrainingCar()` 实际 mesh 的 position 属性和相对车根节点矩阵导出凸体。每侧包含镜背、四段开放镜框、两段支架，两侧共 **14 个实际凸体**。支架本身也有圆角，使用其真实顶点。
- 导出形状为 `type: 'convex'`，包含去重后的车辆局部顶点，以及 `center`、`halfSize`、`axes`。包围盒仅供筛选，最终接触使用凸体支持映射，避免把 RoundedBox 圆角外的空区当成实体。几何单位为米。
- `scene.getSafetyContext()` 同时提供 `egoAttachments` 与 `egoTransform`。后者来自真实 car world transform，包含位置、朝向、坡面俯仰及车根离地量；局部顶点不预加根节点高度，避免重复抬高。
- 镜背、镜框和支架是固定安装件。现有调镜只改变反射镜片顶点，碰撞壳体不会错误地跟随镜片调节角度旋转。
- source geometry 按 position 属性及版本缓存；实际局部 mesh 矩阵变化会刷新凸体。普通车辆运动只更新根节点变换，复用只读局部形状。缓存后的几何导出在一次额外本机 Node 测量中约为 **0.026ms/次**，该数值不代表浏览器整帧性能。

## 窄相与连续检测修正

`course-attachment-collision.js` 对附件凸体与登记障碍物的三维盒体或圆柱包络计算 GJK 距离；连续检测使用分离距离下界推进，并包含相对平移、车身及障碍物旋转。当前附件接触容差为 **10µm**，不是实车感知或测量精度的承诺。

本轮独立复核发现并修复了两条反例：

1. **合法毫米尺寸被扩大。** 旧逻辑将障碍物宽、长的半尺寸最少取 5mm，使 2mm 宽目标在仍有 3mm 间隙时也被判相交。现已保留有效的真实正尺寸，并加入固定回归；圆柱障碍也验证了圆形角部净空。
2. **极窄间隙叠加坡度旋转耗尽迭代。** 实际左镜壳距墙 27µm，俯仰变化 0.1rad，另有 0.000015 或 0.000016rad 的偏航时，旧全局旋转上界过松：终点已相交，连续检测仍可耗尽 8192 次迭代返回未接触，单次探索运行约 320–370ms。现改为把 SLERP 的固定世界旋转轴投影到分离法线方向计算闭合上界。上述接触反例及纯俯仰保持净空的反例均已固定测试，检查采样数 **小于 100**。迭代耗尽不会被直接解释为碰撞。

附件阻断现在保守恢复**本帧已实际检查过的 previous pose**。不把 SLERP 中间姿态简单反解为欧拉角位置后声称精确恢复，因为场景会按道路重新计算高度及俯仰。回归测试重新从恢复位置建立真实 context，再检查没有阻断；初始位置已重叠时则明确标记 `startedUnsafe`，不虚构接触前安全位置。

## 正式自动验证

本轮整合后的 `npm test` 为 **367/367 通过**，其中安全模块 **23/23 通过**。总数包含其他原有功能测试，不表示有 367 个独立镜壳场景。

与本次物理变化直接相关的覆盖包括：

- 实际几何顶点、左右侧别、根节点高度、车身偏航与坡度变换；调镜不转动固定壳体；缓存失效及引用复用。
- 左右镜壳、独立支架擦碰，前进及倒车连续扫掠；两端均安全但中间偏航或俯仰接触的路径。
- 圆角包围盒空区、毫米目标、低矮路沿、高位物体和镜壳高度的区分；镜壳投影越过油漆线不冒充轮胎压线。
- 已存在初始重叠、净空位置向外离开、恢复真实 previous context 后的安全性，以及极窄间隙旋转性能反例。
- 开启实际附件凸体后，对科二、科三全部 **22 章**模型示范，按 0.15s 采样并包含原姿态关键点检查，没有出现新增附件阻断。该检查仍是模型回归，不等于覆盖所有可能驾驶轨迹。

## 仍有的边界

本轮精细几何仅针对本车外后视镜总成。整车车身、轮胎、道路标线仍使用各自原有检测模型；其他交通参与者及场景障碍物仍以登记的三维 box/cylinder 包络表示，**不是所有渲染 mesh 的逐三角形碰撞**。未登记物体不自动获得碰撞检测。

模型不模拟镜壳折叠、弹性、破损、真实车辆悬架与轮胎形变，也不代表某款 C1 教练车的测量标定或真实科目二、科目三考试评分。附件阻断提示表达的是该教学模型内的接触风险，不能据此给出实车通过间隙的保证。
