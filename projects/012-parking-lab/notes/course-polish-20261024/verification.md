## 实现结果

- 统一页面底色、卡片、文字层次、选中态与播放状态。观察 / 当前动作在场景上方，车速 / 挡位 / 灯光 / 踏板集中在场景下方，不遮挡方向盘；暂停或准备时标成“该时刻车速”，避免把示范姿态速度误读为正在行驶。
- 宽屏保留纵向目录并仅滚动目录容器跟随当前项；窄窗口用抽屉目录，支持焦点循环、Escape、遮罩关闭和选章后回到播放按钮。补充跨断点焦点处理、加载时标题焦点兜底及正确的 `aria-modal="true"`。
- 增加专注观看，保留播放、观察提示、视角、看镜、时间轴和语音设置；讲解字幕独立显示，完整说明折叠。播放方式合并为“整科连续播放 / 每项结束暂停”，原状态接口继续同步。
- 暂停讲解后静音保持暂停并取消旧语音 token；整科从头 / 结束重播及切科恢复正前观察，科三上车准备恢复全景，后续自动转驾驶位。普通重看和章节练习继续保留观察操作。
- 原生 3D 环境加入实例化分层树冠 / 枝干、三套楼体立面 / 门厅 / 窗框、人行道 / 铺装接缝 / 低绿化；调整天空、雾、日夜光照和舱内补光。道路与出口延至雾后；给转弯、掉头、学校和公交区域留出空间。
- 主视图 / 镜面 / 阴影按变化刷新，暂停不重复绘制；行人等候时停止原地摆腿，补齐材质释放、异步纹理回调和 WebGL 恢复处理。驾驶位眼位、FOV、物理镜域、原22章示范轨迹及停车线未改。
