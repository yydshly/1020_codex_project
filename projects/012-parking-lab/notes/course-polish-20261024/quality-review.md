# 演示播放器只读质量检查 · 2026-10-24

检查范围：`full-courses.js`、`course-playback.js` 和 `courses.html`。本报告是源码与纯状态复现，不冒充本轮实际页面截图验收；页面视觉证据由主代理另外保存。

## 需要修复

1. **暂停讲解后静音会自动开动。** `course-voice` change 把 `lecture-paused` 和正在讲解一并交给 `skipLecture()`；`skipCourseNarration()` 无条件改成 `playing`。纯状态复现为 `lecture-paused → playing`，再推进 0.25 秒时动作时间从 0 增至 0.25。暂停意图应保留：讲解暂停时关闭语音应进入动作暂停，只有未暂停的跳讲解或明确“用字幕继续”才开始动作。
2. **重看科三首章不恢复绕车观察。** 已经从准备章推进到驾驶位以后，“从头看完整科三”与末尾“重看整科”通过 `activateChapter(0)` 进入准备章，但 `syncChapter` 没有开启 `resetView`，首章沿用驾驶位；绕车人物可能在车外不可见。整科重新开始应使用首章的教学视角，普通暂停、接手和重练继续尊重观察选择。
3. **切科后可能沿用朝镜方向。** `setSubject` 只重设视角，不将 `gaze` 还原正前；在上一科看左镜后切科，新科驾驶位可能仍朝左。应明确新科目起点的默认观察状态，同时保留同章暂停 / 重练的看镜状态。

## 已知呈现问题与实现建议

- 当前目录只更新 `aria-current`，没有在播放到第 14 项以后使其进入滚动容器可见范围。只滚动 `chapter-list`，不要在每次自动跨章时滚动整个页面。
- 当前 HUD 直接显示轨迹时刻的速度，准备 / 讲解 / 暂停时容易被当成车辆仍在行驶。可明确“示范时刻车速”，或者把实际暂停状态与记录值在视觉上分开。
- 车速、挡位、转向灯、灯光、离合 / 脚刹 / 驻车控制全叠在驾驶舱内，窄窗格会占用转向与道路观察空间。核心车速 / 挡位可以简洁保留，详细操作放到画面外；暂停与视角控制应稳定可见。
- 窄窗格不宜继续固定约 198 px 目录侧栏。可收起为目录按钮或项目抽屉；选项后关闭抽屉，并将焦点放到可见播放器控制，避免隐藏焦点。

## 建议的必要回归

- 讲解暂停后关闭语音：保持动作暂停，连续 `advance` 不改变时间；按继续后才动。
- 正在讲解时明确跳过：正常进入动作；过期音频结果不能再改变阶段。
- 从科三末项重看整科：首章显示绕车准备视角；进入灯光 / 道路项目自动回驾驶位；用户主动选择全景仍保留。
- 科三播到目录下半段：当前项目可见且主画面不被强制滚走。
- 窄窗格目录展开 / 关闭 / 选章以及键盘 Escape：当前项目、焦点和播放器状态清楚。

以上问题已逐项反馈主代理。实际修复、测试数量与页面截图以本轮最终验证记录为准。

## 本轮改动复核

主代理修改后的源码复核：上述暂停静音、整科重启准备视角、切科镜面朝向均已修正。目录会在自己的列表内跟随当前项目；新增窄屏抽屉具有 inert、初始焦点、Tab 首尾循环、Escape 关闭和焦点返回。原有跳章、倍速、视角、看镜、讲解重试、字幕继续和返回倒库专项的入口仍保留。播放方式统一为连续 / 每项结束暂停，下层两个兼容状态仍同步。

另反馈两个焦点边界，待主代理决定处理：

1. 窄屏打开目录后，将窗口拉宽到 1050 px 以上，再缩窄；`directoryOpen` 仍为 true，resize 重新启用 modal / inert，却没有调用移入抽屉焦点的路径。可在跨至宽屏时关闭内部打开状态，或在 modal 新开启时迁移焦点。
