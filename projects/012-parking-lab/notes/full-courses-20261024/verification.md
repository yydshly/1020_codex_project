# C1 科二、科三全项目演示 · 实现与验证

本轮把入口从倒库专项扩展到整科教学演示。课程数据、播放器控制、音频资源、自动化与实际页面验收分别记录；旧倒库专项及其历史证据保留。

## 课程范围

- 科目二 5 章：倒车入库（两侧完整路线）、坡道定点停车和起步、侧方停车（入位与驶出）、曲线行驶、直角转弯。
- 科目三 17 章：上车准备、模拟夜间灯光、起步、直线行驶、加减挡位操作、变更车道、直行通过路口、路口左转弯、路口右转弯、通过人行横道线、通过学校区域、通过公共汽车站、会车、超车、掉头、夜间行驶、靠边停车与安全结束。对应 16 项道路驾驶技能，另加模拟灯光示范。
- 当前课程数据的动作时间分别约 227.33 秒与 489 秒，不含每章讲解。动作时长与教学场景之间的切换不代表真实考试时长、里程或某地考线；C1 实考道路里程要求与本教学动画分开说明。
- 科三安全文明驾驶常识理论（通常称科四）不在这份 3D 道路演示内。地方可增加项目，具体口令、车型和考线仍须对应实际考试。

## 入口与播放行为

- 首页直接提供科二与科三入口；`courses.html?course=subject2` / `courses.html?course=subject3` 可直接进入对应课程，保留返回倒库专项。
- 播放器目录显示全项目，默认先讲解、后播放动作并整科连播；支持逐章选择、上一项 / 下一项、重看本项、整科时间轴、动作速度、每项结束暂停和驾驶位 / 全景 / 俯视。
- 讲解暂停和动作暂停为独立状态。跳章、跳时间、换科、主动跳过讲解会使过期语音完成回调失效；语音失败不冒充讲解结束，不自动启动车辆，必须重试或明确选字幕继续。
- 异步重试语音在网络等待前后检查请求与章节身份，避免换科后旧重试返回而启动新章。浏览器往返缓存保留暂停状态；真正离开才销毁场景。
- 当前轨迹采用按章教学姿态与插值，不等同于可接手驾驶的完整科二 / 科三考试物理系统。原倒库自由驾驶、镜面辨认、纠偏、分步示范与复盘继续保留。

## 语音集成

新课程使用 22 个课程 narration key，与旧 48 个倒库 key 区分。MiniMax 仍由本地离线生成器读取用户指定的项目外配置，浏览器只读取公开 manifest 和 MP3，不接收密钥。旧倒库页面只校验原 key 子集；课程页只校验课程子集，避免新增课程缺包时破坏原倒库语音。

本轮 22 段课程语音均已真实生成，共 7,453,176 字节、463.464 秒，全部通过 FFmpeg 完整解码；旧 48 段清单元数据与文件 SHA-256 逐一核对、原样保留。当前活动包共 **70 段、16,155,384 字节、1,002.204 秒**，继续使用 `speech-2.8-hd / male-qn-qingse`。精确文本、文件、字节数、时长、哈希与解码结果见 [audio-generation.json](audio-generation.json)；生成前活动清单保留为 [manifest-before.json](manifest-before.json)。
