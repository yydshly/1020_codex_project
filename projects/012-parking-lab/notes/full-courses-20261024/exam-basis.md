# C1 科目二、科目三全项目演示依据 · 2026-10-24

## 核对的一手来源

- [北京交管公布的《机动车驾驶证申领和使用规定》（公安部令第 172 号）](https://jtgl.beijing.gov.cn/jgj/jgxx/flfg/gabgz/543498902/index.html)：页面载明 2025-01-01 施行；第 33 条列明 C1 科目二五项，第 34 条列明 16 项道路驾驶技能及小型汽车至少 3 公里、未安排夜考时进行模拟夜间灯光考试，第 35 条将安全文明驾驶常识列为另一部分。
- [深圳交警：场地驾驶技能（科目二）预约、考试](https://szjj.sz.gov.cn/ZTLM/ZT_JDJSZSB/CCLCT/content/post_11738826.html)：核对小型汽车五项与小型自动挡四项的区别。本次仍按用户此前选定的 C1 保留坡道项目。
- [深圳交警：道路驾驶技能及常识（科目三）预约、考试](https://szjj.sz.gov.cn/ZTLM/ZT_JDJSZSB/CCLCT/content/post_11738825.html)：交叉核对道路项目范围。

本轮不以旧网帖、网传“新增项目”或驾校口诀替代现行法规。地方可按规定增加项目；考试城市与实际车型未提供，因此本次先做全国通用项目的教学串联。

## 实现覆盖

科目二五章：

1. 倒车入库：复用原低速运动模型生成的完整 A 端右倒库、出库换边、B 端左倒库和返回起点。
2. 坡道定点停车和起步：接近、定点停车、制动保持、建立离合结合点、解除驻车制动并向前起步。
3. 侧方停车：车位前方准备、倒入、车身顺直后停稳、观察打灯并向前驶出。
4. 曲线行驶：连续左右弯、回轮换向及驶出。
5. 直角转弯：接近参照、转弯、留意内后轮与外前角、沿出口回正。

科目三十七章覆盖正式 16 项道路技能，并单列模拟灯光：

上车准备 → 模拟夜间灯光 → 起步 → 直线行驶 → 加减挡位 → 变更车道 → 直行通过路口 → 路口左转 → 路口右转 → 人行横道 → 学校区域 → 公共汽车站 → 会车 → 超车 → 掉头 → 夜间行驶 → 靠边停车与安全结束。

这份顺序用于学会完整流程，不称为当地考试固定顺序。模拟灯光演示近光、远光、会车转近光、远近交替、近距离跟车、故障妨碍交通且难以移动时示警，以及结束复位；不宣称穷尽各地随机口令组合。夜间动态行驶独立保留，没有用静止灯光片段冒充完整夜间道路技能。

## 数据与场景的一致性

- 统一使用米、秒与弧度；姿态位置是后轴中点，+Z 为初始前进方向，+X 为驾驶员左侧，正前轮转角表示向左。显示车速由 m/s 转换为 km/h。
- 左转驶向 +X 后进入横向道路 z=21.75 的右侧车道；右转驶向 −X 后进入 z=18.25 的右侧车道。该约定防止画面把正确转向演成驶入对向车道。
- 变道和超车在同向双车道场景中演示，不用跨越双黄实线的轨迹解释一般超车。
- 斑马线中心 z=15、深 3.3 m；让行停车后轴 z=8.8，车头最前端 z=12.34，早于停止线 z=12.6，也早于斑马线入口 z=13.35。行人通过期间车辆停住。
- 侧方停车的库内静止姿态以完整车身包围几何检查；直角转弯以完整车身及 L 形道路检查，不只让后轴路径看起来没越线。
- 坡起先保持驻车制动，将离合调整到结合点，再解除驻车制动并前进。离合 HUD 区分踩下、结合点和松开，而非显示“踩到底同时车辆向前”。
- 转向灯先显示一段观察时间，再开始变道、驶出或靠边动作。演示里显示的时长不是可机械照搬的实考计时口诀。

## 适配和演示边界

每章切换到明确命名的独立教学位置，不伪装成车辆瞬移后还在同一条连续实测考线。科目三的教学路段不构成法规要求的完整至少 3 公里实考路线，也不替代驾驶人科目三安全文明驾驶常识题库。

除原倒库沿用运动模型外，新增章节采用编排轨迹和姿态插值，以看懂观察、打灯、挡位、制动和方向的先后关系为目标。没有模拟发动机扭矩、真实离合脚感、轮胎侧偏、完整碰撞或当地电子考试评分。坡度、挡位与速度的示例不作为所有教练车的统一参数；停车点、镜面点位和操作量仍需教练按车辆与座椅标定。

动作时长不含每章先播放的 MiniMax 讲解、用户暂停或切换。科二动作合计约 227.33 秒，科三动作合计 489 秒；“完整观看”表示全项目教学顺序完整，不表示一次连续实考计时或考试合格。

`src/exam-courses.test.js` 覆盖项目完整性、语音文本和时间轴有效性、姿态插值、低速倒库双侧、坡停后起步、完整侧方入位和驶出、直角车身边界、转弯出口通行方向、灯光类型与复位、人行横道停让和超车后的回道距离。实际页面证据由本轮主验证记录另行保存。
