    卡片怎么组成

    气泡 + 人物图 + 两个徽标

    上方是台词气泡，中间是人物 JPG，左上角叠加状态名，右下角叠加 emoji。打盹时还会出现飘动的 💤。原版把画面裁进 10:11 的区域；图鉴保留完整原图。

    “情绪”怎么产生

    收到状态，再换对应画面

    待机、思考、干活、打盹表示持续状态；鼓掌、疑问、比心用于短暂反馈。这是我们按配置做的分类。表情与台词营造情绪感，桌宠本身不会从聊天内容推断心情。

    动作是什么

    静态姿势与页面动画分开看

    原图里的挥手、敲键盘、鼓掌都是定格。源码另配有呼吸、摇摆、弹跳等 CSS 动画；当前版本图片的动画选择器与实际结构不匹配，不能把配置名称当作已生效的人物动作。

    展开：状态流转、接入方式与原始来源
    点击 / CLI / 宿主通知→设置状态→切换图片、徽标、台词→临时状态计时回待机

    单击依次切换：待机 → 思考 → 干活 → 鼓掌 → 疑问 → 比心 → 打盹 → 待机。双击直接鼓掌。拖动移动的是浏览器页面内的卡片，位置保存在该浏览器。

    CLI 可明确指定七种状态。Codex 通知桥将开始事件映射为干活、完成事件映射为鼓掌、错误事件映射为疑问；需要宿主实际发出通知并完成接入。图鉴选择只切换说明，不向原版发送命令。

    鼓掌 6 秒、疑问 8 秒、比心 5 秒后返回待机，由原版页面的计时器执行；其他状态没有自动回落计时。另有可选 DSH 会话文件监视器，依据最近修改时间切换干活、待机和打盹，并不理解对话。
