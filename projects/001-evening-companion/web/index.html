01 / 我们的理解

图片承担情绪表达，Agent 承担对话与任务。

这个库把“宿主 Agent + 思考与表达 Skill + 图片桌宠”组合起来。它提供了情绪化呈现的产品形态，但还不是独立、完整的 AI 女友应用。

A

宿主 Agent

提供大模型推理、对话上下文与工具执行能力。聊天和任务在宿主中发生。

能力底座 · 依赖外部宿主
B

原版 Skill

用提示规则组织倾听、澄清、判断与写作方式，指导宿主模型如何回应。

行为与表达规则 · 仓库提供
C

图片桌宠

根据点击、命令或已接入的宿主通知切换人物图片、状态徽标和预设台词。

情绪化展示层 · 仓库提供
点击 / 命令 / 宿主事件→设置状态→切图片 + 徽标 + 台词
它的启发是把能力和形象分开。

不用等待角色建模、绑定、口型与动作全部完成，也能先探索有存在感、有反馈的陪伴产品。是否让人愿意持续交流，可以先用轻量形态验证。

02 / 桌宠实际效果

七种画面，表达状态与情绪感。

下面展示原库的七张人物图片，点击可查看大图。原版桌宠会在人物图上叠加状态名与 emoji，并在上方显示预设台词气泡；emoji 只是辅助徽标。

7 张静态图片21 句预设台词4 个持续状态3 个临时反馈

原版怎么互动？

单击按顺序切换，双击鼓掌，拖动移动页面内的卡片。鼓掌 6 秒、疑问 8 秒、比心 5 秒后回到待机。页面可见时每 9 秒随机抽取一条该状态的预设台词，可能重复。

图片能接入更多效果吗？

可以在后续改造中加入转场、缩放、粒子、序列帧或 2D 动画。原版图片本身是静态的；本次版本的图片动画选择器有层级不匹配问题，不能把源码中的动画名当作已运行的效果。

图片直接引用自 cyberxiaowan/cyber-xiaowan · pet 的固定研究版本。鼓掌图为作者实拍，其余六张为同一人设生成的动作图。图片版权与肖像权归原作者，未复制进本研究仓库；加载依赖 GitHub 图片服务。

03 / 对我们的价值

把 3D 变成升级项，先做出陪伴。

我们一直被 3D 实现卡住。这个库提供了一个可借鉴的过渡形态：先用图片表达情绪，把真正影响陪伴的能力逐步补齐。

01

图片 + 真实聊天

接入真实模型，用一组角色图片响应对话状态。

验证：用户愿不愿意聊
02

记忆 + 主动互动

增加可管理的长期记忆，以及可配置的主动触发机制。

验证：能否持续陪伴
03

动效 / 2D 表现

围绕对话反馈丰富转场、姿态和情绪表达。

验证：表现是否提升体验
04

按需升级 3D

继续复用对话、记忆与交互逻辑，升级角色表现层。

验证：收益是否值得投入

以上是我们的扩展路线，尚未在原库实现。记忆、主动互动和自由聊天界面需要另行开发。

不必一次到位：先做能陪伴的版本，再做更立体的她。
