# v0.1 验证记录

日期：2026-10-20。

用户故事：在本地界面与角色交流 → 保存一条偏好 → 重启页面后回忆 → 安排主动提醒 → 免打扰时暂缓，解除后送达。

## 实际验证

| 边界 | 结果与证据 |
| --- | --- |
| 服务启动 | `npm start` 输出 `http://127.0.0.1:4317`，模式 `offline demo` |
| 页面渲染 | 在 Codex 内置浏览器打开，看到原创插画、聊天、导航和功能入口 |
| 聊天保存记忆 | 点击“记住我的小偏好”，导航计数从 0 变成 1；回复带“记忆已保存”标记 |
| 刷新持久化 | 执行页面刷新，记忆数仍为 1，原对话仍在 |
| 记忆召回 | 点击“你还记得什么？”，回复包含此前保存的雨天和热茶 |
| 记忆编辑 | 在记忆页将内容改为“喜欢雨天和热茶（体验示例）”，保存后展示新内容 |
| 免打扰 | 开启后安排 10 秒提醒，到期显示“已到时间 · 免打扰结束后送达” |
| 恢复提醒 | 关闭免打扰后，聊天中出现“主动关心”消息 |
| 迷你卡片 | 点击入口后显示人物小窗、最近消息与聊天按钮 |
| 核心自动化 | 5 项通过：非事实过滤、称呼更新、重复记忆、免打扰与只送一次、坏数据恢复 |
| 服务集成 | 2 项通过：使用模拟上游验证请求/回应/错误/越界访问；无配置返回离线状态 |

集成测试的模型是测试用模拟服务，不是真实模型。没有使用外部模型密钥或声称已验证自然语言效果。

## 证据与限制

实际截图：`assets/cover.png`、`assets/mini-preview.png`。

验证数据是“雨天和热茶”等测试示例，不是从用户其他文件推断的信息。原型保留该示例供用户直接查看；后续可在记忆页修改或删除。
