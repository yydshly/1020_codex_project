## 来源事实

上游：[Leonxlnx/napali](https://github.com/Leonxlnx/napali)。本地下载 commit 为 `4afb7c3a1aad3d0203193100305c46607134d0f5`，许可为 MIT，作者 Leon Lin。

README 描述了以 WebGL2 着色器与 JavaScript 生成海岸、海水、植被、天空和镜头的作品。作者称使用 Claude Code / Claude Opus 5.5，经历 13 轮开发与参考照片对比。发布版影片为离线渲染的 1080p30；音乐来自 Kevin MacLeod，未包含在仓库中。

`index.html` 包含描出的海岸向量轮廓 `COAST_IMG`、地形引导数据和大量艺术调整参数。结合作品专用的镜头路径，我们据此判断：它是针对一个场景精调的程序化视觉作品，而不是任意地理场景生成器。参考照片未包含在原库，不能据此宣称地理测绘级还原。

## 我们的分析

可迁移的是“意图 → 场景规则 → 时间与镜头 → 可观看或可交互作品”的制作思路。需要持续选择参考、构图、配色和节奏。规则可以帮助重现和复用空间，但不会自动完成艺术判断。

扩展方向分为：自己的风景、时间变化、观众进入、空间故事、知识旅程、制作工具。六类是候选路径，先用小样检验体验，再扩充内容和技术复杂度。
