## 本地启动与验证边界

正常入口为 [Start-Project.ps1](../Start-Project.ps1)。在仓库根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\projects\014-programmable-worlds\Start-Project.ps1
```

脚本准备项目独立运行器，检查或隐藏启动本地 8796 静态服务，然后打开完整首页。正常入口采用与隐藏验收相同的 OpenGL 后端和项目专用配置目录。脚本已通过解析和准备检查，完整首页已隐藏实测；可见窗口由用户执行入口后打开，本轮没有自动显示它。

原作首次运行需要编译大型着色器并生成场景。D3D11 的独立编译试验在 20 分钟上限内未完成 `FS_RENDER`，没有进入场景或驾驶检查，见 [独立结果](source-compile-d3d11.json)。因此正式入口固定为已验证的 OpenGL；其他浏览器保留明确标注的试运行按钮。

性能记录按实际边界解释：原作一个隐藏区间完成 8 帧用时 8.218 秒；停止源库 GPU 提交后，空闲 RAF 中位间隔仍为 1004 毫秒，隐藏合成器本身约每秒调度一次。原作海面样本一帧工作的墙钟约 327 毫秒，包含 CPU、GPU 等待与协作调度，并非纯 GPU 计时。当前记录不构成稳定可见帧率承诺。各机位具体计时保存在原始报告。

隐藏验收只调用项目自己的 DOM 与 API，窗口 `show=false`、不获取焦点，不使用系统输入或桌面截图。页面截图在两次自身 RAF 后捕获，避免旧加载层或字幕尚未提交。验收进程结束后已释放 GPU；本地静态服务保留供用户打开。
