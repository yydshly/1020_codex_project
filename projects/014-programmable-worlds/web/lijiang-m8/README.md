# 漓江晨航 · M7 性能候选

此目录独立保留 M6 的山群形态、统一 2 米世界采样网格、植被与完整倒影，优化生成调度和交互渲染。当前正式入口及候选状态以项目 notes/lijiang-current.json 为准。

生成侧复用最终规格的主峰结果，将连接域采样与 CPU 网格处理重叠；不改变采样点、标量场或植株布局。极远景仅省去亚像素细枝索引，保留全部叶簇、成年主干、根点、材质和实例，可同场切回基线比较。

交互使用最多两帧在途的 GL fence 队列，帧数仅在 GPU 实际完成后增加。定点截图、导出与恢复仍先等待队列完成，再执行严格完成帧渲染。串行/流水线两种调度可同场对照；排队提交次数不作为真实帧率。

首次生成、定点热帧、连续驾驶和画面对照分别记录。离线 1080p60 不代表实时60帧。M6、M5及原作/运河作品均保留。
