# 008 · 产品发现平台图谱

把本次对话对 Product Hunt 与同类平台的理解整理成中文研究网页：平台围绕什么组织内容、用户为什么访问、创作者如何参与，以及这些线索怎样用于竞品研究与需求验证。

本项目研究的是六个在线平台，而非六个可安装的开源代码库。Product Hunt 帮助发现新品、分析竞品与组织发布；Uneed 提供目录和排期等展示渠道；BetaList 帮助早期项目招募注册者和测试用户；AlternativeTo 帮助寻找软件替代方案并比较差异；Indie Hackers 提供获客、定价与创业经营经验；新趣集支持中文产品展示和交流。对个人的共同价值是节省发现与比较的时间、接触反馈和同行，并为是否继续做一个产品收集证据；实际转化和市场需求仍需验证。

## 核心结论

Product Hunt 是以产品为中心的发布、发现和交流平台。参与者既可以是独立创作者，也可以是公司团队；账号、产品归属、产品主页与一次发布是不同概念。主页和发布资料的管理不等于产品开发、订单或客户管理。

六个平台虽然相互重叠，但组织内容的重心不同：

| 内容中心 | 平台 | 用户进入的主要理由 |
| --- | --- | --- |
| 产品发布与发现 | Product Hunt、Uneed、新趣集 | 发现新品、发布作品、交流反馈 |
| 早期项目 | BetaList | 找到刚起步的创业项目、参加试用 |
| 软件替代 | AlternativeTo | 从已知软件寻找更适合的选择 |
| 创业过程 | Indie Hackers | 学习做产品、获客和经营的方法 |

这四类是研究归纳，不是官方分类。平台关注、真实使用、复用和付费是不同层次的信号；没有用点赞或排名证明市场成立。

## 网页内容与能力

1. **核心理解**：四类内容中心与平台边界。
2. **六个平台**：分类筛选、单个平台档案、核心能力与依据。
3. **横向对比**：选择 2–6 个平台，比较内容中心、人群、发现入口、互动、阶段、参与、费用、语言、价值与边界。
4. **理解 Product Hunt**：个人和公司、主页和发布、社区和官方、收费与中文、平台和专项活动。
5. **按目的选择**：发现新品、发布作品、招募内测、研究替代品、学习经营；附同一假设产品的六种参与方式。
6. **从发现到验证**：明确任务、收集问题、同任务实测、访谈交付、复用付费；包含失败回路。
7. **总览引导图**：沿用本次生成的 PNG，展示六个平台的作用、对我的价值与使用顺序；支持放大和原图下载，另保留详细流程 SVG。
8. **来源与边界**：19 条官方资料，可搜索；事实、判断、未验证事项分别说明。

页面提供窄屏布局、键盘焦点、表格独立横向滚动、研究笔记下载和打印样式。页面是纯静态文件，可直接打开，不依赖外部字体、CDN、账号、API 或数据库。

## 本地运行

直接用浏览器打开 `web/index.html` 即可使用。也可在仓库根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File projects/008-product-platform-atlas/preview.ps1
```

访问 <http://127.0.0.1:8088/>。端口占用时可添加 `-Port 8098`。结束预览可在运行服务器的终端按 Ctrl+C。

重新生成理解图和研究笔记：

```powershell
python projects/008-product-platform-atlas/src/build_guide.py
```

检查文件与来源引用一致性：

```powershell
python projects/008-product-platform-atlas/src/verify.py
```

```text

assets/platform-guide.svg 完整矢量图
notes/research.md        含来源的研究记录
notes/verification.md    实际验证结果
src/build_guide.py       生成图与笔记的可复用脚本
src/verify.py            内容一致性与资源检查
```

更新资料先修改 `web/data.js`，再同步主页面中的静态结论，最后运行生成器。生成器会更新本子项目的理解图和笔记副本，不改其他项目。发布只需要整个 `web/` 目录。

## 资料与验证边界

- 资料快照：2026-10-23。正式提交产品前复核收费、语言、收录标准与活动日期。
- 本次工作是研究内容整理和本地网页实现，没有代用户提交产品、购买推广或参加比赛。
- 没有实际测量平台流量、获客转化、留存、收入或市场规模。中文本地笔记软件为解释差异的假设案例。
- 新趣集的发布价格未完整核实，明确标注为待确认。
- 讨论起点的 Astra 合作活动指定 2026-09-18 发布，不能把历史活动当作当前报名指引。
- 当前范围不展开自建平台的扩展功能规划。
- `project.json` 的仓库地址指向本研究集，并非这六个平台的源代码仓库。
- 本项目通过仓库的 GitHub Pages 工作流发布；部署结果和原图校验记录见 `notes/release.md`。

个人使用时，先用平台节省发现和比较的时间，再把投入放在可接触的用户、重复任务和实际结果上。
