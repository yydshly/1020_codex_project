# 街道与小猫体感试作 01

本地入口：<http://127.0.0.1:8062/roam-refine.html>。点击“进入老街”，再点击“走一段看看”，观察店前约 10 米街道中的步行、启停与转身。右上角“上一版对照”返回保留的漫游原版。

## 范围

本轮使用原有 `roam-02.glb`、街区尺寸、导航与障碍代理。新版只新增 HTML 和 JavaScript 入口及精修模块，原研究页、旧漫游页、Blender 工程和导出资产不覆盖。本轮没有扩展街区、下载外部模型或进行 Cycles 渲染。

精修街段的 Three 坐标为 x = -7 至 3 米，临店前一侧。其他位置仍可沿用已有路线浏览，但不作为本次美术质量验收范围。新增地面表面与原导航地面保持约 3 毫米差值，角色不会因视觉铺地改变而被抬高一层。

## 本轮变化

- 10 米地面采用新的自制颜色、法线与粗糙度贴图，在新版运行时遮蔽这一小段旧地砖表面；墙、木料和石材加入局部表面变化，收紧阴影覆盖范围以改善近处接触感。
- 独立小猫模块采用连贯的躯干、颈部与头部表面，缩小头身比，增加毛色变化。四肢由有关节位置的连续表面驱动，支撑阶段保留落足位置，抬脚阶段回摆；依旧是轻量实时程序角色。
- 普通步行速度由 1.65 改为 0.72 米/秒，按住 Shift 以 0.48 米/秒慢走；加入加减速、碰撞后速度回写与暂停清惯性。本轮只提供步行，避免快速起步时腿部伸长限位造成明显滑步。
- 默认镜头降低至离地约 1.26 米，观察点前移，沿街看过去；保留拖动环视、滚轮、触屏和建筑遮挡检测。
- 自动演示改为本街段往返，方便观察相同资产在多个位置和动作中的效果。
