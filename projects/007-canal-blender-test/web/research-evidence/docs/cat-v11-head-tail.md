# V11 头尾随运动协调

用户指出头部和尾巴持续保持同一姿态。V11 在已接受的 V10 走跑、收掌和连续权重表面上新增独立协调层，旧版文件和原模型完整保留。未增加场景或模型复杂度，未发布远程网页。

## 行为

- 尾巴从绑定中性姿态重新计算。待机、步行、小跑分别逐渐后放，避免累积旧版旋转。转弯反向偏移，尾中段和末端延迟跟随，停车后平滑回稳；没有持续左右摇摆。
- 头部在小跑时下压约6.6°，转弯时有限看向路线。街道控制器传入期望方向，急转减速时也能提前观察。头颈采用猫身体坐标系下的朝向，减轻肩部摇摆传给头部的影响。
- 保留原约56°头部校正、手动左右看/低头及眨眼。停用头部动作时尾巴仍随走跑协调。
- 新近景页提供直行/左转/右转、速度切换、V10同速对照。转弯后点击观察视角会依照猫当前朝向重新定位。老街08使用同一模型模块，导航和场景沿用07。

## 验证

`assets/cat-v11-secondary-motion-audit.json`：51项CPU检查通过。30fps、60fps和抖动帧间隔下，12个腿部骨骼世界矩阵与V10完全一致，网格51976三角形、源资产哈希不变。实测尾尖步行约35.5cm、小跑约24.7cm，小跑伸向身后；头随转弯约±8.2°。手动姿态、恢复自然、重复重置通过。

首次审计保留在`cat-v11-secondary-motion-first-audit.json`；其中重置误报来自测试未归一化四元数，归一化后通过，运行代码没有为此修改。

浏览器实际检查了载入、小跑、左右转、V10同速切换、停车、转头与闭眼贴合。截图保存在`assets/cat-v11-run-side.png`、`cat-v11-comparison-v10-run.png`和`cat-v11-head-eyelid-check.png`。

老街08实际载入、起步转向和小跑通过，控制台没有错误；截图为`assets/cat-v11-street-running.png`。原web目录177个文件的SHA256均未改变，见`assets/cat-v11-preservation-check.json`。本地服务仅监听127.0.0.1:8062。

这是针对当前模型绑定的程序动画，并非实拍动作捕捉。源模型尾端仍带C形弯钩，既有后腿与腹部皮肤拉扯仍未解决；本轮不声称达到真实猫运动的完整效果。
