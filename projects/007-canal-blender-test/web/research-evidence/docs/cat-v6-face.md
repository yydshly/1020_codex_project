# V6：独立眼睑试样

本轮针对 V5 闭眼时眉额毛纹被向下拉伸的问题，保留全部旧版本，新增独立眼睑和两个本地入口：`web/cat-v6-face-study.html`、`web/shop-study-03.html`。嘴部和独立眼球注视仍未制作。研究站主页未改，没有发布。

## 实现和使用

V6 直接沿用 V4 的猫、步态和头部动作，不使用 V5 的面部压缩形变。原身体顶点、UV、材质、骨骼和皮肤权重保持不变。根据原眼区表面采样新增四块曲面眼睑，合并为一个蒙皮网格，跟随同一套头颈骨骼。闭合由上下眼睑覆盖眼区，眉额本身不再被牵拉。

新增 1,672 个顶点、2,976 个三角形；猫的总三角形从 49,000 增至 51,976，增加约 6.1%。街道模型、范围、镜头和路线没有增加或改变。新版漫游控制器只更换猫模块及版本标识。

近景页支持睁眼、半闭、闭眼停留检查，单次和自动眨眼，左右转头、低头、步行，以及 V5 对照。普通眨眼约 0.28 秒。V5 没有半闭控制，对照模式会禁用该按钮。

新眼睑沿用原贴图中的毛色小区域，并加入轻微颜色颗粒；没有修改原图，也没有新增凹凸贴图。可用毛色区域的有效采样很小：上睑约 9×9／11×11 像素，下睑约 5×5 像素。新增细分只能改善曲面轮廓，不能还原缺失的毛发细节。

- 浏览器：`assets/cat-v6-face-final-browser-check.json`，36 项通过，脚本及着色器错误为零；覆盖真实按钮、头部动作、眨眼、半闭、V5 对照、步行和手机布局。
- 保留：`assets/cat-v6-face-final-preservation-check.json`，本轮开始前记录的 476 个文件逐文件 SHA256 均未改变。
- 漫游：`assets/shop-study-03-smoke-check.json`，10 秒实际行走检查通过；522 个采样全部可行走，速度不超过 0.6 米／秒，脚点目标误差为零，行走中有头部动作和完整自动眨眼，无浏览器或着色器错误。

## 质量边界

这版解决了 V5 通过压缩原面部来闭眼的结构问题，睁眼时原猫形象保持不变。近景闭眼仍能看出独立眼睑与原毛发之间的色差和拼接感，部分边缘仍偏硬。它是可比较、可漫游的功能试样，尚未达到真实猫近景的细腻程度。

后续最有价值的修正是专用眼睑 UV、与周围毛流相接的表面纹理及眼缘过渡，必要时局部重拓扑和分离眼球。单纯加密网格或加大动作幅度无法解决目前的表面限制。模型仍来自此前采用的 Grab3D CC0 猫，原资产和许可均保留。
