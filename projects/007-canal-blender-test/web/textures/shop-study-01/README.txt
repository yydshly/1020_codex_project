All image bytes were downloaded directly from the publisher's file API links,
verified against its MD5 values, and preserved without editing. The full URLs,

No code, plugins, or geometry were downloaded.

Assets and physical tile coverage:
- cobblestone_floor_05: 2.0 x 2.0 m. Worn stone pavers with irregular rounded
  edges and dirt-filled joints. This is a dry PBR material: wetness must be
  modeled in the scene material, not described as already captured rain.
- worn_plaster_wall: 1.8 x 1.8 m. Grey-beige chipped plaster with pronounced
  peeling. Use selectively or with restrained color blending to avoid turning
  the maintained shop into a ruined building.
- wood_planks_grey: 1.5 x 1.5 m. Weathered neutral-grey wood with vertical
  grain and seams. For green painted shop frames, prefer normal/roughness and
  preserve the existing paint color; using diffuse at full strength darkens
  the frame and introduces plank seams/nail details.

Each asset has 1024 x 1024 diffuse JPG, normal OpenGL PNG, roughness JPG,
and ambient-occlusion JPG. Diffuse uses sRGB; other maps are linear data.
No displacement map is included, so these do not increase mesh complexity.
Total image download: 14,695,347 bytes (approximately 14.0 MiB).
