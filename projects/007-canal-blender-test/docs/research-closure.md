本轮补齐三档入口图，统一图生 3D 的能力、探索过程、结论与意义，并按用户授权准备提交远端、部署研究网页。保留全部已有版本，不继续建模、渲染或场景优化。2026-10-25 上一次收束整理的范围是仅本地预览；本次新增的提交与部署授权已覆盖该限制。发布结果以实际部署与线上核验记录为准，本文不预先视为已上线。

## 结论

**本次已经实现图生 3D：从一张参考图出发，生成可编辑、可换角度渲染并能进入漫游的三维场景。** 具体路线是 Codex 理解图片，通过本地 Python / Blender bpy 重建几何、材质、灯光与相机，创建、保存、重开、修改和渲染场景，再导出 GLB 接入 Three.js，逐步形成有限范围的户外街区。这一成果超过了仅证明 Blender 能被连接或调用。

这里的图生 3D 是看图后程序化建场景，不是从单图精确恢复真实扫描；遮挡区域、背街、河弯和院落包含后续设计。高保真还原参考图仍未完成，所有室内也未构建。没有安装、实跑 DSH / MCP，没有同图、同资产、同预算的 DeepSeek / Codex 对照，因此不能据此排名模型或源库。

前期主要以类似氛围为目标，V4 才显式进行相机与布局对齐，不能把前几版的差异全部解释成有计划的阶段迭代。V4 指标是人工选点投影误差，不是整图相似度。V5 几何与湿面两轮各只有两张低清候选，均未被接受为最终高清结果。

## 三档入口与取舍

我们没有只生成一张图。三档原图保留了测试范围的选择过程：

1. **初始候选**：三间店、一座桥，提示中约束五盏灯与一棵树，先确定雨后临水街景的氛围。
2. **高复杂度候选**：约 10–12 栋建筑、两座桥、电车与多层道路，显著增加空间组织、遮挡、资产和后续补景的工作量。
3. **最终预算版**：回到三间店、一座桥与约三盏灯，排除电车、阶梯山城等范围，保留精致感和雨后氛围；它是三档中最后选定的最简单方案，也是唯一实际建模输入。

上述数量描述当时提示的设计约束，不是通过图像检测得到的精确计数。三档用于理解范围与投入的取舍，未做三图分别建模的实测，更不能从它们得出严格的难度或模型性能排名。

## 最终状态与投入产出

保留 SPACE11，最新可编辑几何基础仍来自 SPACE10。可沿既有道路、两岸、桥和部分小院行走。住宅室内、私人庭园、完整交互与生产级质量不在完成范围。

10 的基础 GLB 为 252,502 三角形 / 16,325,100 bytes；11 运行层新增 51,949 三角形 / 3 draw calls。基础 GLB 含隐藏批次，不能相加当可见总量。21 栋只指重建外围住宅批次，另保留核心商店等。

单次机器执行与渲染记录不等于研究总耗时。未统一记录人工 / 代理工时、token、订阅摊销、完整失败尝试和能源，因此总费用 / 工时未知。免费资产仍有筛选、兼容、绑定、烘焙、适配与署名成本。

这次探索的意义是验证了一条从图像到可编辑三维、再到网页漫游的实际路线。它适合快速搭建空间原型、参数化修改、批量摆放与导出，也说明可以用成熟资产降低从零建模的成本。连接工具和生成基本场景较容易，构图准确、空间合理、材质写实与角色自然才是主要投入。

早期图生 3D、控制与对齐验证研究回报较高；后期角色和环境逐项微调，仍未改变整体原型感，新增知识有限，故停止继续优化。结论不是“只能连接 Blender”，也不是“照片级生成世界已解决”：可编辑空间原型已经实现，进一步精修存在明显成本与收益边界。
