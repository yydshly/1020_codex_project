# V5：保留头部动作，新增眨眼试样

用户明确选择本轮同时补转头、低头和眨眼，嘴部留后续。新增独立入口 `web/cat-v5-face-study.html`，V3、V4 及街道样板页面全部保留。新增实际漫游入口 `web/shop-study-02.html`，仅将猫工厂换成本轮版本；环境、镜头、速度和导航沿用样板 01。本轮没有改街道、嘴部或独立眼球注视。

## 使用

默认自然转头和自动眨眼。可以点“眨一下”，或用“睁眼／闭眼”保持状态检查形变；支持左右转头、低头、步行和 V4 对照。正常眨眼约 0.28 秒，快速闭合、短暂停留、较慢睁开；自动间隔有变化。

## 实现与保留

原猫只有连续的带贴图网格，没有独立眼睑环线或眼球结构。根据原贴图在模型表面的投影，分别定位两眼的局部坐标、眼角和开口。新增 `Blink_Left` 和 `Blink_Right` 两个局部位置与法线形变目标；眼区向细闭合线收拢，周围皮肤过渡到闭合位置。没有修改原贴图，也没有叠二维遮罩。

新 GLB `web/models/cat-v5-face.glb` 在原 GLB 后追加形变数据，保留原基础顶点、索引、UV、材质、皮肤权重及骨骼。猫仍为 49,000 个三角形。两侧分别影响 276／330 个导出顶点。运行模块直接调用 V4 工厂，校验网格一致后只移植形变目标；原 V4 的走路和转头实现继续使用。

`artifacts/cat-v5-face.blend` 是独立可编辑 Blender 文件，包含 Basis、Blink_Left、Blink_Right 形状键。原 Blender 文件未覆盖。

## 验证

- CPU 回归：`scripts/check_cat_v5_face.mjs`，对照 V4 检查 30／60 FPS 共 1800 帧的全部骨骼、脚点、步态及头部姿态；检查形变端点、自动循环、局部范围和法线。
- 浏览器：`scripts/check_cat_v5_face_browser.py`，检查单次和自动眨眼、保持睁闭、头部动作、V4 对照、步行、手机布局及实际点击；保存截图与约 8 秒动作录像。
- 保存基线：`assets/cat-v5-preservation-baseline.json`；逐文件结果在 `assets/cat-v5-preservation-check.json`。
- 模型来源仍为此前采用的 Grab3D CC0 猫，原许可保留。新形变的数据和方法在 `web/models/cat-v5-face.json`。

最终模型 SHA256 为 `5661824659aa02bfb99f71a18d0f4e9a1bbb11eafefb56afcb4d21a486aed9a7`。CPU 回归中全部骨骼（含头部）、脚点与步态在 1800 帧内的差值均为零。最终浏览器检查 30 项通过，脚本和着色器错误为零。392 个已存在文件的最终校验值全部未变，结果见 `assets/cat-v5-preservation-final-check.json`。

最终页面素材使用 `assets/cat-v5-face-final-*` 前缀；`cat-v5-face-final-motion.webm` 为预热后约八秒真实动作片段，原始录制保留为 `-motion-raw.webm`。此前无 `-final-` 的素材是过程中检查，不能用于代表最终模型。

新版漫游也已实际检查：10 秒内沿原路线行走约 5.125 米、完成两次自动眨眼，全部采样可行走，无浏览器／着色器错误。检查和截图在 `assets/shop-study-02-smoke-check.json` 与 `assets/shop-study-02-follow.png`。

## 实际质量边界

这版是几何眨眼功能试样。闭合时已消除明显的绿色眼球残留；动作与走路可以同时运行。原面部三角面较粗，闭眼时仍能看见上眼区毛纹拉伸、眼角略硬，短时眨眼不等于这些问题已消失。

如果要做长时间闭眼、近景特写或丰富表情，下一步需要局部眼睑拓扑、分离眼球及相应 UV／闭眼表面处理。单纯继续加大现有网格的形变量无法解决这一结构限制。嘴部本轮未制作。
