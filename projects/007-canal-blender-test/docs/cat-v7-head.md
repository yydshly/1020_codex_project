# V7：纠正行走时持续偏头与头颈拧动

用户指出新版漫游中猫的头部别扭。本轮检查发现，原猫表面自带约 55.995° 的侧向朝向，身体前方为 +Z；此前 V4 的小幅转头只是叠加在这个姿态上。原动作每帧还原骨骼，并不存在累计旋转，但没有把“正常行走时脸朝向路线”作为验收项。

原蒙皮另有结构问题：上半脸几乎完全跟随头骨，下脸和下颌大部分跟随颈骨。即使小幅转头，也会让上下脸的运动不一致。直接将原头骨回转 56° 会进一步放大这个问题。

## 本轮修改

新增 `web/cat-v7-head-skin.js` 和 `web/cat-v7-head.js`，沿用 V6 的眼睑及原步态。仅在新的猫实例上复制蒙皮网格，重新分配 4,349 个顶点的骨骼权重，使前部面孔和双耳保持整体，后颊和颈部逐步过渡；26,705 个腿尾相关顶点保持原权重。原模型文件、顶点位置、法线、UV、三角形索引均未修改。

在原支点施加约 -55.995° 基准修正，使脸朝向身体前方；没有平移头骨。去掉原骨局部轴上的持续小幅摇摆，在校正姿态上添加短暂、缓慢的小幅观察动作。行走时优先看前方，自然观察进一步减小；手动转头限制为站立 ±6°、移动 ±2°，低头最高 3°。这些是本模型的保守试样范围，不是猫的解剖极限。

眼睑随面部统一跟随头骨，保留单次、自动和停留检查。新增部分不增加任何顶点或面：整只猫仍为 V6 的 51,976 个三角形。

第一轮权重过渡与腿部保护边界不连续，导致侧颈出现尖片。根据实际变形边长定位后，将过渡起点移到该边界上方，并让嘴部和后颈在不同高度逐步接入头部。所查颈部最大边长倍率从 8.21 降至 3.49；这表示尖片显著减轻，不代表剩余拉伸已经消失。

## 入口和版本保留

- `web/cat-v7-head-study.html`：默认全身 3/4 视角，正面、侧面、脸部、头部动作、眨眼、步行及同机位 V6 对照。
- `web/shop-study-04.html`：新版猫接入原街道样板，环境、相机、导航、速度和路线沿用 03。
- 旧 V6 及 `shop-study-03.html` 完整保留。研究站主页未修改；没有提交或发布。

## 证据与质量边界

局部蒙皮短检见 `assets/cat-v7-head-skin-check.json`，边长审计见 `assets/cat-v7-neck-edge-audit.json`。最终预览使用 `cat-v7-head-final-` 前缀，早期 `initial`、`seated`、`smooth` 截图仅供过程比较。

- 完整 CPU 回归：`assets/cat-v7-head-matrix-check.json`，53 项通过。30／60 FPS 共 1,800 帧，除头骨外全部骨骼矩阵、脚点、步态与 V6 的差值为零。72 个面部核心和耳部样本的两两距离最大误差约 2.34e-8 米；眼孔及眼睑均随头骨运动。
- 浏览器：`assets/cat-v7-head-final-browser-check.json`，22 项通过，无脚本或着色器错误，覆盖同机位 V6 对照、转头、眨眼、步行、停止和手机布局。
- 漫游：`assets/shop-study-04-smoke-check.json`，8 项通过。10 秒实走 4.441 米，完成 2 次眨眼，528 个采样均在可行走区域，最大速度 0.6 米／秒，脚点目标误差为零；沿用原场景和导航。
- 动态画面：`assets/cat-v7-head-final-motion.webm`，7.567 秒／228 帧，记录最大帧间隔约 58 毫秒；这不是所有设备的帧率保证。
- 版本保留：`assets/cat-v7-preservation-check.json`，528 个旧版本文件 SHA256 及大小均未变。另两个运行中的本地预览服务日志按运行日志单独记录，不作为版本不变断言。

正面和侧面能观察到默认朝向已改变，侧颈尖片明显减轻。近景下颊和白色颈毛仍有拉伸，V6 的闭眼皮片感也仍然存在。本轮主要修正头部朝向与面部联动，没有把原扫描表面重建成高质量角色拓扑，也没有实现嘴部或独立眼球注视。后续需要局部重拓扑或专门的校正形变才能进一步改善这些表面问题。
