# Cat V9：行走与小跑；表面修整试验未采用

2026-10-24。本轮只新增本地版本，保留 V8 和此前街区；不扩街道，不添加道具，不发布研究站。

## 入口与操作

- `web/shop-study-06.html`：WASD/方向键移动，Shift + 方向键小跑，C + 方向键慢走。触屏可切换“小跑模式”后按方向。急转先减速，障碍前提前制动，松键逐步停下。
- `web/cat-v9-gait-study.html`：0.24 / 0.36 / 0.90 m/s 选择，开始移动；保留同速 V8 行走对照、头部动作和眨眼。
- 旧版 `shop-study-05.html` 和 `cat-v8-gait-study.html` 保留。

## 本轮行为

V9 做轻快小跑（trot），并非完整疾跑（gallop）：右后/左前、左后/右前两组交替，距离驱动步频；稳定跑速 0.9 m/s，步幅 0.34 m，支撑比例 0.40。周期约 0.378 秒；这些是适配当前模型的动画参数，不是猫的通用生理阈值。

小跑使用独立抬脚曲线、短暂腾空、支撑压缩与回弹，尾根后放；在走跑之间渐变。恢复步的结束时刻回到共同落地相位，避免某一只脚提前开始另一套周期。停止时过远的脚立即收回，减少僵直拉腿。原头部和眨眼功能保留，嘴部未制作。

街道控制器根据停止距离探测原有导航范围，接近墙/花盆时提前减速；仍使用原有碰撞处理作为兜底。不会扩充可走区。

## 表面修整试验：已拒绝

最终 V9 默认保留 V8 的表面权重，不读取修整候选资产。`createCat(THREE, {surfaceSkin:true})` 仅供同姿态诊断页复现未采用的试验；正式试样和街道均不传此选项。

曾尝试在既有表面邻接上平滑局部权重并限制梯度。它保护脚底、头颈、尾部，保持模型位置、法线、UV、索引和骨骼数。同一 V9 跑姿的 21 个采样帧、38,140 条区域边：最差边长放大 8.5467 → 6.2637，P99 3.9448 → 3.0174，P95 2.4597 → 2.1499。预烘焙资产也将读取/校验/应用降至约29ms。

**这些数值改善没有转化为可接受的外观。**严格同骨骼、同相机对照出现新的胸腹/腿根裂口。追加检查6,083对跨UV岛近邻点：原版最大缝隙0.82mm，1μm分组试验57.65mm；0.05mm和0.1mm两个候选分别仍有17.14mm和12.11mm。全部拒绝；原报告、二进制和对照图保留作失败证据，正式入口未采用。边长指标遗漏了扫描网格不同索引之间的连续性。

最终视觉边界：腿根仍有扇形拉伸，前胸/肩部体积和关节弯曲仍不够自然，眼睑仍是附加表面。这轮可试走试跑，但不能称为真实猫动画已完成。更大改善应从适合动画的腿部拓扑、接缝连续约束、体积修正及绑定入手，不能继续仅按几个拉伸统计调权重。

## 验证

- `check_cat_v9_gait.mjs`：真实 GLB 的骨骼变换足底，30/60 Hz 起步、走跑切换、刹停、原地转向与复位；脚掌支撑滑移、触地误差和落地配对。
- `check_cat_v9_transition_jitter.mjs`：走路过程中切跑，30/60 Hz 和抖动帧间隔；核对真实足底超过 3 mm 的腾空，未只看动画标志。
- `check_cat_v9_obstacle.mjs`：直接执行街道生产控制器的移动函数，组合真实导航与猫，包含 60 ms 慢帧、障碍、急转、松 Shift、停止；抽样真实脚底网格顶点。
- `check_cat_v9_browser.py` / `check_shop_study_06.py`：实际浏览器键鼠/触屏、表情、相机与录屏。
- `check_cat_v9_surface_browser.py`：同相机、同骨骼姿态修整前/后对照，不用不同姿态伪装表面改善。

已知测试余量：组合抖动时序首次起跑，右后摆动脚曾出现 14.35 mm 目标误差，接近 15 mm 检查上限；急转瞬间足底锚点离地约 7.34 mm。自动检查通过不能代替自然度判断。
