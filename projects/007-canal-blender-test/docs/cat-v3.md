# 猫形重做 V3

本地街区入口：<http://127.0.0.1:8062/roam-cat-v3.html>。

独立形体检视：<http://127.0.0.1:8062/cat-v3-study.html>，可查看正面、侧面、背面、脸部近景、行走，以及上一轮程序猫对照。

## 为什么更换外形基础

前两轮主要用程序曲面和基础几何拼出猫。即使改动头身比例，原来沿身体纵向延伸的头颈与口鼻仍容易形成犬科轮廓，面部和毛色也缺少可信细节。本轮先保存程序雕塑尝试，再采用外形更成熟、许可明确的猫模型，进行减面和骨骼适配。

原始模型来自 [Grab3D Tabby Cat](https://grab3d.com/models/animals/cat/)。发布方将模型和贴图置于 CC0 1.0，并注明由 Meshy 生成基础模型后在 Blender 清理。该外形不是本项目从零雕刻的成果，也不是从我们的老街参考图中自动重建出来的。

原始下载、许可文本和来源记录分别保存为 `web/models/cat-v3-reference-source.glb`、`cat-v3-reference-source.LICENSE.txt`、`cat-v3-reference-source.json`。原文件包含静态模型和贴图，不含骨骼或动画。

## 本轮实现范围

- 将模型适配到已有街区的米制尺寸、地面高度和朝向；保留原始模型作为对照。
- 为网页准备减面版本，加入腿部、头与尾部骨骼，再由浏览器步态控制驱动。
- 网页角色由原始 382,505 三角面减至 49,000 三角面，使用 21 个骨骼，GLB 约 2.69 MB；保留两张原始 1024 像素贴图。
- 沿用原有导航和碰撞；普通步行 0.60 米/秒，Shift 慢走 0.40 米/秒。
- 改变方向时先换脚转身、接近对齐后再前进，限制身体转速，避免身体突然转过仍固定在地面的脚。
- 初始状态让猫面向镜头附近，方便先看到脸；自动演示沿原来的店前样板街段行走。
- 原街区模型、环境材质、旧漫游入口和上轮精修入口均保留，未扩大场景，未发布。

## 验收

```powershell
node --test projects/007-canal-blender-test/tests/test_cat_v3_controls.mjs
python projects/007-canal-blender-test/scripts/check_cat_v3.py --video
```

除功能和几何检查，还需要直接看不同角度及行走录像：短口鼻和面颊是否保留，肩腋和腹部是否塌陷，脚掌是否分离或穿地，尾根是否折断。自动检查通过不能代替这些外观判断。

本轮采用有限的运动学步态与空间分区权重，尚不等同于经过完整手工权重绘制、动物动作捕捉和物理模拟的角色。猫的毛色来自模型纹理，没有逐根毛发模拟。快跑、跳跃和复杂地形动作不在本轮范围内。
