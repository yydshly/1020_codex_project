# 对岸建筑 03

这一轮按用户要求，细化对岸既有三栋住宅的屋顶、门窗与墙面，使之与书店一侧更协调。保留所有已交付版本，不扩街区，只提供本地预览。

## 入口与文件

- 预览：`http://127.0.0.1:8062/scene-space-03.html`
- 新场景：`artifacts/rainy-canal-space-03.blend`
- 新导出：`web/models/space-03.glb`、`space-03-manifest.json`
- 组装脚本：`scripts/build_space_03.py`
- 几何模块：`refine_space_03_roofs.py`、`refine_space_03_facades.py`、`refine_space_03_plinths.py`
- 网页材质：`web/scene-space-03-environment.js`，继承 SPACE02 的街区材质与原有灯光。

页面提供整排立面、沿街近看、门窗、屋顶、侧墙、全景、书店与背面八个机位，以及同镜头“上一版 / 对岸精修”切换。两条原有巡看路线保留。上一版入口为 `scene-space-02.html`，未更新研究站、未发布。

## 最终变化

屋顶：仅替换三个原 `ClosedRoof` 的网格数据，新增实厚屋面、666 片错缝薄曲瓦、48 段脊瓦、封边、檐口、雨槽与落水管。均为基础网格，不依赖导出时会被禁用的细分或倒角修改器。最大水平外挑增加约 0.10 米、屋脊增高约 0.117 米；网页中压低少数亮瓦反差，避免方块补丁感。

门窗和墙面：在新副本隐藏六个旧实心墙壳/黑板门窗批次，替换为 28 厘米厚、带真实浅洞口的四面墙。30 扇窗有窗套、窗台、细窗棂、蓝灰反射窗片；正面上层百叶采用不同开角。六扇门保持关闭，增加门套、分格与把手。少量外露石块用于侧墙局部修补，两处窗片有克制暖色。墙面在原抹灰纹理上补少量低频色差与窗台下淡水痕；材质和灯光尺度延续书店一侧。

门口校正：浏览器近看发现旧石基上沿为 1.17 米，遮住原本低至 .875 米的门扇。最终只替换三块 `StonePlinth` 网格，在六处门口将 .40 米深的小段降至 .925 米，接到现有 7.5 厘米门槛。基础底层连续，缺口外石基和原 bounds 不变。门芯单独调整为暗棕木，窗后背板继续保持暗色。

地形、水面、桥梁、两岸路线、院落、远景和主街三间店铺沿用 SPACE02。未增加灯、房屋、角色或散置道具；室内未开放，窗后为封闭的浅层次，并非完整室内建模。

## 规模与验证

最终 GLB 为 **174,012 三角形、34 个材质批次、10,553,228 字节**；相对 SPACE02 净增加 10,334 三角形（约 6.31%）。新增 15 个几何对象，仅位于三座原房屋周边；新副本还保留被隐藏的旧对象及旧石基网格。

最终只读报告 `assets/space-03-postcheck-final-r2.json`：**52 项通过**。

- 130 个既有文件哈希不变。
- 522 个路线样点通过；30 个原支撑完全一致，3 个门前探针命中预期新增的 .925 米门槛。
- 只允许六个旧对象隐藏，三个屋顶与三块门口石基更换网格。其他旧对象、材质、地形、水面、桥和院落均保持。
- 门口凹口、连续底层与未改石基区域经多点表面/体积检查；原水平包络与材质槽保持。
- 初次审计中，隐藏墙壳重开后的派生矩阵未求值，显示 identity；复核确认其持久位移、旋转、缩放、矩阵基底与原网格都未改变。初次报告和诊断保留，以上述 final-r2 为最终结论。

JavaScript 语法与实际 GPU 材质编译通过。浏览器观察了整排立面、门窗、屋顶、侧面、背面和沿街视角，并测试版本切换及巡看。最终截图和网页检查记录位于 `artifacts/scene-space-03/`，以 `*-final.png` 为最终材质/门口修正效果。

这轮改善了原对岸“薄屋顶、贴黑板窗”的主要问题。住宅立面仍较规则，玻璃采用现有天空反射与封闭浅层次；最终写实度仍受简化环境光照和未制作完整室内影响。
