# 几何配置

geometry.original.json 从固定上游 index.html 提取，保持原作数据。复制后修改，并通过场景配置中的 geometry 字段引用。

| 字段 | 每条记录 | 用途 |
|---|---|---|
| COAST_IMG | `[x0,y0,x1,y1,...]`，一个数组是一条闭合轮廓 | 第一条为大陆，后续为海蚀柱/岛礁 |
| VALLEYS_IMG | 一条谷地包含多个 `[x,y,谷底高度米,半宽米]` | 山谷轴线与谷底 |
| CLIFFS_IMG | `[x,y,高度米,抬升宽度米]` | 沿岸岩壁控制 |
| MASSIF_IMG | `[x,y,峰高米,半径米]` | 连续基形上的山体抬升 |
| BEACHES_IMG | `[x,y,半径米,海滩坡率]` | 海滩裙边 |
| SHELVES_IMG | `[x,y,半径米,强度]` | 浅海台地 |

x/y 是原作 1672×941 参考画面中的坐标，通过固定参考机位反投影成世界坐标。不要把它们当成以米为单位的世界坐标；不要顺手修改参考机位 camH/pitch/vfov。

模板构建器会替换这些 JavaScript 数据数组，保留 GLSL 算法。原作局部岩壁修形等逻辑还带有海岸题材的坐标假设；改变布局以后需要检查，而不是认为换完轮廓就已经获得完整的新地貌。
