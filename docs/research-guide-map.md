# 研究项目的完整引导图要求

用户于 2026-10-23 明确要求记住：研究项目需要一张完整引导图，对我们的理解进行整理和汇总，说明来源或这个库带给我们的思考，展示从需求确定到最终独立站搭建的流程，并讲清对个人的参考价值，信息尽可能全。

## 后续整理应保留的内容

- 先说明来源解决什么、核心原理是什么、我们从中得到哪些思考，再连接到自己的选择与执行。
- 用一张完整图串起总流程；每个阶段给出动作、产物、通过条件、对个人的用途，必要时画出失败后回到哪一步。
- 区分来源的原始能力、我们自己的理解、候选方案与已经验证的结果；标明事实、推断、假设、资料时间和来源。
- 对经营类项目，前置需求与获客，区分用户、受益者与付款者；不要只展示代码、功能或部署架构。
- 把需求、人群与渠道、竞品、价值样例、产品形态、最小实现、域名与部署、验收、真实使用和复用收费连接起来。
- 解释参考价值：如何筛选方向、决定下一步、控制投入、判断问题发生在哪一段，以及哪些经验可迁移到后续项目。
- 图中信息尽可能完整，同时保持层次和文字可读；提供可放大浏览及原图下载。图本身不能只是装饰封面或几个标题箭头。
- 网页正文保留更多细节与可点击来源；README 中展示完整图，索引封面/图说明应与实际内容一致。相关内容变化时同步更新图。
